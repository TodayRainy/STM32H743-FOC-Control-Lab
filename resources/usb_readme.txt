USBD配置阶段回调函数->设备配置->设置地址->设置新的USB地址
USBD配置阶段回调函数->设备配置->获取描述符->发送  设备描述符
USBD配置阶段回调函数->设备配置->获取描述符->发送  设备配置描述符

USBD配置阶段回调函数->设备配置->获取描述符->发送  字符串描述符  :发送  语言字符串
USBD配置阶段回调函数->设备配置->获取描述符->发送  字符串描述符  :发送  设备产品名称字符串

USBD配置阶段回调函数->接口配置
USBD配置阶段回调函数->获取描述符

发送  字符串描述符  :发送  语言字符串\r



复合设备 更换msc, cdc, 要修改usbd_desc.c里的设备配置描述符 端点号要从0x01开始, 对应的设备接口号也要从0(不是要从1始, 是其他的端点没有设置fifo)

对应设备的接口配置要从0开始
#define USBD_CDC_FIRST_INTERFACE     0x00
#define USBD_MSC_FIRST_INTERFACE     0x02

之前msc cdc不能同时使用的一个重大原因, 没有给多个端点设置fifo, 要在USBD_LL_Init 中添加HAL_PCDEx_SetRxFiFo, 给对应的端点设置fifo大小

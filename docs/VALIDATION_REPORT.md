## 验证目标

阶段 0 不追求把所有高级算法一次完成，而是回答：

1. 电流、速度、位置三种模式能否进入、运行和停止；
2. 是否有足够的运行时可观测量；
3. 能否在一次上电内连续执行多个工况；
4. 软件示波器是否能记录 40 kHz FOC 变量且开销可接受；
5. 后续优化是否有可重复比较的基线。

## 小电流阶跃

默认阶段 0 电流点按 iq:id 格式：

~~~text
0:0 → 0:+0.2 A → 0:-0.2 A → 0:0
~~~

即 iq 保持 0，id 做小阶跃。

| id 参考 | 上升时间 | 滤波后超调 | 稳态值 | 原始峰值 |
|---:|---:|---:|---:|---:|
| +0.2 A | 约 125 μs | 约 23.5% | 0.20004 A | 0.482 A |
| -0.2 A | 约 175 μs | 约 13.35% | -0.19999 A | 0.591 A |

观察：

- 稳态跟踪准确；
- 正负瞬态不完全对称；
- 单次数据不足以区分偏置、噪声和真实控制不对称；
- 进入参数辨识前应进行小规模重复性验证。

## 位置阶跃

相对进入位置模式时的当前位置测试：

~~~text
+2° → -2° → +5° → 0°
~~~

结果：

- 第一次 +2° 阶跃出现约 ±1.3° 持续摆动；

- 后续 -2°、+5°、回零相对稳定。

这是阶段 0 最重要的未闭环现象。候选原因：

- 第一次进入位置模式时积分和参考初值；
- 位置、速度、电流三环带宽关系；
- 静摩擦、齿槽和编码器量化；
- 轨迹切换和最短路径逻辑；
- 单次采集偶然性。

下一步应先判断是否可重复，再决定修改控制器还是记录为偶发数据问题。

### 诊断版暴露的问题

首轮连续 RL+磁链中，RL 给出 `Rs=151.067 mΩ`，正反扫和拟合 RMSE 合格，但留出 RMSE 为 11.01 mV，略超筛选线。随后单独重复 RL 时，出现：

## ABZ 角度归一化与测速器离线重放

2026-08-25 在不连接目标、不烧录和不启动电机的条件下完成 D-034 第一批离线验证。

TIM3 编码器计数范围为 `0..4095`。原实现使用 `CNT/ARR*2π`，使最后一个计数映射到 `2π`，随后计数 0 产生重复角度样本。当前实现提取纯函数 `foc_encoder_count_to_mech_angle()` 并使用 `CNT/(ARR+1)*2π`；主机回归遍历全部 4096 个状态，机械角步长约 `0.00153398 rad`，包括回绕在内的最大浮点步长误差约 `4.73e-7 rad`。

现役速度估算在 40 kHz 对电角度差分后做 500 点滑动平均，代数上等价于 12.5 ms 位置差分。理论群延迟约 6.24 ms、矩形窗 -3 dB 约 35.4 Hz、首个陷波点 80 Hz。`tests/encoder_speed_estimation.py` 使用既有 scope 的 `elec_angle` 重放该 BASE，并提供 1–2 ms短窗+IIR和临界阻尼编码器 PLL 候选。20 Hz速度正弦记录中，BASE 对固件 `elec_speed` 的 RMSE 约 `0.512 rad/s`，相对约 `200 rad/s` 的动态量很小；80 Hz记录中 BASE 输出接近陷波，和既有硬件现象一致。

离线证据边界：既有 scope 保存的是采样后的电角度，不是原始 TIM3计数边沿时间，因此不能重建低速M/T；这些记录采集时 BASE 已在速度反馈闭环内，也不能用同一轨迹证明WIN-IIR或PLL接入闭环后一定更优。当前结论仅为角度数学修正和离线模型链路有效，新测速器尚未取得硬件资格。

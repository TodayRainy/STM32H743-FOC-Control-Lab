# 阶段 0 验证报告

报告日期：2026-08-24

阶段：控制与测量基础

结论：具备继续开展参数辨识和三环自整定的基础，但位置首次小阶跃问题尚未闭环

## 验证目标

阶段 0 不追求把所有高级算法一次完成，而是回答：

1. 电流、速度、位置三种模式能否进入、运行和停止；
2. 是否有足够的运行时可观测量；
3. 能否在一次上电内连续执行多个工况；
4. 软件示波器是否能记录 40 kHz FOC 变量且开销可接受；
5. 后续优化是否有可重复比较的基线。

## 软件示波器验证

配置：

- 10 通道；
- 4096 点；
- 160 KiB D2 SRAM 缓冲；
- 1/10/100 分频；
- 串口和 J-Link 两种读取路径。

| divider | 采样率 | 时长 |
|---:|---:|---:|
| 1 | 40 kHz | 102.4 ms |
| 10 | 4 kHz | 1.024 s |
| 100 | 400 Hz | 10.24 s |

实时性：

- 最大记录开销约 124 CPU cycles；
- 480 MHz 下约 0.258 μs；
- 占 25 μs FOC 周期约 1.03%。

因此当前软件示波器能够支撑电流环、速度环和短位置过程研究。它只能记录软件变量，不能替代功率级物理示波器。

## 小电流阶跃

默认阶段 0 电流点按 iq:id 格式：

~~~text
0:0 → 0:+0.2 A → 0:-0.2 A → 0:0
~~~

即 iq 保持 0，id 做小阶跃。

| id 参考 | 上升时间 | 滤波后超调 | 稳态值 | 原始峰值 |
|---:|---:|---:|---:|---:|
| +0.2 A | 约 125 μs | 约 23.5% | 0.20004 A | 0.482 A |
| -0.2 A | 约 175 μs | 约 13.35% | -0.19999 A | 0.591 A |

观察：

- 稳态跟踪准确；
- 正负瞬态不完全对称；
- 单次数据不足以区分偏置、噪声和真实控制不对称；
- 进入参数辨识前应进行小规模重复性验证。

## 空载速度点

测试速度：

~~~text
500 rpm → 0 → 1500 rpm → 0 → 3000 rpm → 0
~~~

前馈 OFF 和 ON 使用相同速度序列。

结果：

- 三个速度点均稳定；
- 母线约 23.98 V；
- 未观察到电压矢量饱和；
- 低中速前馈差异较小；
- 高速有轻微收益迹象，但不足以证明当前参数下前馈已经最优。

速度点证明空载速度环和连续自动化链路可用，但不代表带载调速性能。

## 位置阶跃

相对进入位置模式时的当前位置测试：

~~~text
+2° → -2° → +5° → 0°
~~~

结果：

- 第一次 +2° 阶跃出现约 ±1.3° 持续摆动；
- 同期速度约在 ±25 rpm 附近往复；
- 后续 -2°、+5°、回零相对稳定。

这是阶段 0 最重要的未闭环现象。候选原因：

- 第一次进入位置模式时积分和参考初值；
- 位置、速度、电流三环带宽关系；
- 静摩擦、齿槽和编码器量化；
- 轨迹切换和最短路径逻辑；
- 单次采集偶然性。

下一步应先判断是否可重复，再决定修改控制器还是记录为偶发数据问题。

## 自动化能力

tests/stage0_validation.py 在一次运行中完成：

1. 等待电流校准和 READY；
2. 检查母线电压；
3. 小电流点；
4. 多速度点；
5. 前馈 OFF/ON；
6. 正反位置偏移；
7. 每阶段软件示波器；
8. 原始遥测 CSV；
9. JSON 指标报告；
10. finally 中发送 STOP 并确认 READY。

默认阈值：

- 最大电流 3 A；
- 最大速度 4000 rpm；
- 母线 18–28 V。

自动化提升覆盖效率，但不会自动扩大用户批准的工况范围。

## 结论

当前已经具备：

- 基础三环；
- 安全启停状态机；
- 运行时 PI 和轨迹命令；
- 40 kHz 软件示波器；
- 批量自动化；
- 主机算法回归；
- 构建、烧录、观测工具链。

因此可以继续进入电机参数辨识和三环自整定研究。

在正式宣称“位置环稳定可用”前，仍需复核首次位置小阶跃。MTPA、弱磁和无感控制应建立在参数辨识和稳定基线之上。

## 验证边界

当前不能据此宣称：

- 带载转矩响应；
- MTPA 效率最优；
- 弱磁恒功率能力；
- 热稳定；

这些边界是实验条件限制，不是通过软件估算可以替代的内容。

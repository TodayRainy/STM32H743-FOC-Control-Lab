# FOC 控制优化与研究路线

本路线图是能力地图，不是固定工期，也不是不可调整的线性清单。阶段编号用于表达主要依赖；允许在证据充分时并行、跳过或返回前一阶段。

## 总体目标

建立一套从“可运行 FOC”到“可解释研究项目”的完整链路：

~~~text
可靠观测与自动测试
        ↓
基线问题闭环
        ↓
电机与机械参数辨识
        ↓
三环系统化设计与自整定
        ↓
电压约束、MTPA、弱磁与无感控制
      ↙                         ↘
机器人控制分支                 新能源电驱分支
~~~

每个能力都尽量形成四项产物：

1. 算法假设与数学依据；
2. 清晰、克制的嵌入式实现；
3. 自动化或半自动化实验；
4. 原始数据、指标和适用边界。

## 阶段 0：观测、自动化与基础控制

目标：证明三环和实验链路可用，并获得后续算法可以比较的基线。

已有基础：

- 电流、速度、位置模式运行；
- 串口命令与遥测；
- 软件示波器；
- 连续自动化脚本；
- CSV 和基础动态指标；
- dq 前馈开关对比入口。

尚需闭环：

- 首次位置小阶跃极限环是否可重复；
- 正负电流瞬态差异的重复性；
- 当前固件基线、参数和结果之间的可追溯关系。

建议退出条件：

- 三个控制模式可以重复进入和安全停止；
- 关键动态指标能够由脚本重复计算；
- 没有未解释的稳定持续振荡；
- 后续算法有固定的对比基线。

## 阶段 1：电机与机械参数辨识

目标：减少凭经验填参，为电流控制、解耦、弱磁、MTPA和观测器提供模型参数。

优先候选：

- 定子电阻 Rs；
- d/q 轴电感 Ld、Lq；
- 永磁磁链或反电动势常数；
- 转矩常数和电气量单位一致性检查；
- 转动惯量、黏性阻尼、库仑摩擦的空载近似；
- 参数随电流、速度和温度变化的初步敏感性。

实现方向：

- 激励、采样、估计和有效性判断分层；
- 优先离线拟合，稳定后再考虑在线辨识；
- 保存原始波形和拟合残差，不只输出一个参数；
- 用不同幅值和方向重复，给出置信范围或离散程度。

空载条件下电气参数和磁链具有较高可行性；机械参数只能作为特定空载装配的近似，不能等同于带载模型。

建议退出条件：

- 参数单位、符号和坐标定义明确；
- 多次估计具有可接受的一致性；
- 参数能预测至少一组未参与拟合的响应；
- 结果能够被后续控制器设计直接使用。

## 阶段 2：三环系统化设计与自整定

目标：形成“辨识—计算—实验—评价”的闭环，而不是只保存一组手调 PI。

电流环：

- 依据 Rs、Ld/Lq、采样和计算延迟选择目标带宽；
- 计算 PI 和积分限幅；
- 验证电流阶跃、交叉耦合、饱和与参数误差；
- 比较手调参数与模型设计参数。

速度环：

- 使用机械参数或小信号实验模型；
- 在电流环带宽约束下设计速度环；
- 评价上升时间、超调、稳态误差、峰值电流和正反向一致性。

位置环：

- 基于已验证速度环设计；
- 处理位置轨迹、速度限制、模式切换和积分初值；
- 评价小角度、大角度、正反向和连续轨迹。

自整定不追求“一键万能”。第一版可以是主机脚本自动激励、拟合和生成建议参数，再由用户确认烧录或运行时下发。在线全自动整定只有在安全边界和有效性判断成熟后再考虑。

建议退出条件：

- 参数计算过程可解释且可复现；
- 自动建议参数在预定义工况上不劣于基线；
- 三环带宽关系、限幅和饱和行为有数据支持；
- 失败时能安全回到零输出，而非堆叠复杂预测性防御。

## 阶段 3：解耦、前馈与电压约束

目标：把现有 dq 交叉耦合和反电动势前馈从“代码存在”提升为“参数正确、收益可量化”。

候选内容：

- 基于辨识参数校正解耦项；
- 开启/关闭前馈的相同轨迹对比；
- 电压矢量限制、抗积分饱和和 PI tracking；
- 母线电压波动补偿；
- SVPWM 电压利用率和进入饱和前后的行为；
- 参数失配敏感性。

空载下适合验证高速电流跟踪、电压裕量和速度扩展，但对负载扰动收益的结论有限。

## 阶段 4：MTPA 与弱磁

MTPA：

- 建立 IPMSM/SPMSM 参数和算法适用性判断；
- 实现电流轨迹生成、限幅和与电流环接口；
- 用模型和空载数据验证轨迹连续性、符号、约束和模式切换；
- 没有负载/测功设备时，不宣称已经证明同转矩最小电流或效率地图。

弱磁：

- 以电压幅值、母线电压和电流上限为约束；
- 设计基速以上的负 d 轴电流策略；
- 验证速度扩展、母线变化、饱和和退出弱磁过程；
- 空载条件下可做较可信的速度扩展验证，但不能代表带载恒功率能力。

MTPA 与弱磁可以共用电流轨迹和约束管理，但不要求第一版同时完成。

## 阶段 5：无感控制

目标：利用现有编码器作为参考真值，定量研究估计角度和速度。

候选路线：

- 中高速：反电动势、磁链或滑模观测器；
- 低速：高频注入或混合估计；
- 启动：对准、开环加速、闭环接管；
- 全速域：多观测器切换、失锁判断和降级；
- 鲁棒性：Rs、L、磁链误差和母线波动敏感性。

每一步应同时记录编码器角度和估计角度，报告误差分布、相位延迟、速度范围和失效条件。无物理示波器仍可开展控制算法研究，但硬件注入波形、开关噪声耦合和功率级问题只能有限判断。

## 阶段 6：方向化完善与项目表达

机器人控制分支：

- 位置轨迹与跟踪误差；
- 低速和反向平稳性；
- 摩擦、齿槽转矩和扰动补偿；
- 扰动观测器或扩张状态观测器；
- 机械装配变化下的鲁棒性。

新能源电驱分支：

- 参数辨识与参数漂移；
- 快速转矩/电流响应；
- MTPA、弱磁和电压饱和；
- 无感控制与模式切换；
- 故障状态管理和约束控制。

最终展示应包含：

- 系统结构和硬件边界；
- 一条完整的算法推导—实现—测试案例；
- 自动化实验和软件示波器；
- 基线与优化后的量化对比；
- 失败案例、限制和下一步，而不是只展示电机能转。

## 当前条件下的可行性

| 方向 | 可行性 | 当前边界 |
|---|---|---|
| 三环与自动化评价 | 高 | 空载性能 |
| Rs、Ld/Lq、磁链辨识 | 较高 | 温升和大电流范围有限 |
| 惯量、摩擦辨识 | 中 | 只代表当前空载机械系统 |
| PI 设计与自整定 | 高 | 扰动/带载验证有限 |
| 解耦、前馈、电压约束 | 高 | 负载收益难完整评价 |
| 弱磁速度扩展 | 较高 | 不能证明带载恒功率 |
| MTPA | 中 | 可验证算法轨迹，难证明效率最优 |
| 中高速无感 | 较高 | 以编码器为参考，空载为主 |
| 低速 HFI | 中 | 注入噪声和硬件带宽待实测 |
| 效率/转矩地图、热验证 | 低 | 缺少测功、负载和温度测量 |
| 栅极/开关波形验证 | 不具备 | 缺少物理示波器 |

## 路线调整规则

- 新阶段不是以“代码写完”为完成，而是以实验证据和可复现性为准。
- 出现基础稳定性问题时允许回退，不把回退视为路线失败。
- 算法收益在当前硬件条件下无法验证时，可以保留实现和仿真，但必须明确标注未完成硬件验证。
- 每次只选择一个主要研究问题，测试基础设施只按它的需要扩展。
- 路线变化记录在 docs/DECISIONS.md；本文件保持能力层面的中长期视角。

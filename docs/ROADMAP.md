# FOC 控制优化与研究路线

本路线图是能力地图，不是固定工期，也不是不可调整的线性清单。阶段编号用于表达主要依赖；允许在证据充分时并行、跳过或返回前一阶段。

## 总体目标

建立一套从“可运行 FOC”到“可解释研究项目”的完整链路：

~~~text
可靠观测与自动测试
        ↓
基线问题闭环
        ↓
电机与机械参数辨识
        ↓
三环系统化设计与自整定
        ↓
电压/电流约束、弱磁与无感控制
      ↙                         ↘
机器人控制分支                 新能源电驱分支
~~~

每个能力都尽量形成四项产物：

1. 算法假设与数学依据；
2. 清晰、克制的嵌入式实现；
3. 自动化或半自动化实验；
4. 原始数据、指标和适用边界。

## 阶段 0：观测、自动化与基础控制

目标：证明三环和实验链路可用，并获得后续算法可以比较的基线。

已有基础：

- 电流、速度、位置模式运行；
- 串口命令与遥测；
- 软件示波器；
- 连续自动化脚本；
- CSV 和基础动态指标；
- dq 前馈开关对比入口。

阶段结论：

- 三种模式、STOP/READY、软件示波器和连续脚本均已形成可重复入口；
- 历史首次位置小阶跃持续摆动已定位为外位置轨迹与遗留内速度RAMP重复整形，D-052已从固件入口消除；
- 后续阶段的源码默认、原始数据和机器摘要已持续记录，阶段0未决项由阶段1/2实验证据闭合或重新界定。

建议退出条件：

- 三个控制模式可以重复进入和安全停止；
- 关键动态指标能够由脚本重复计算；
- 没有未解释的稳定持续振荡；
- 后续算法有固定的对比基线。

## 阶段 1：电机与机械参数辨识

目标：减少凭经验填参，为电流控制、解耦、弱磁和观测器提供模型参数。

当前优先范围：

- 定子电阻 Rs；
- d/q 轴电感 Ld、Lq；
- 永磁磁链或反电动势常数；
- 转矩常数和电气量单位一致性检查；
- 参数随小信号激励幅值的初步敏感性。

已完成的首轮硬件闭环包括 Rs/Voff 正反扫描与留出点、Ld/Lq 双幅值注入、磁链双向多速度拟合与留出点。当前实验条件下不强行辨识转动惯量、黏性阻尼、库仑摩擦、温度系数或饱和图谱；这些内容只有在获得相应转矩、温度或负载基准后再进入范围。

2026-08-24 的模型 A/B 进一步确认前馈相对关闭有明确收益，但空载条件不足以区分两组 Ld/Lq 前馈。阶段 1 的基本电气模型、独立留出和控制用途检查已达到当前实验条件下的退出要求；下一主线转入阶段 2 电流环系统化设计，机械参数继续延期而不是用低可信数字填充。

实现方向：

- 激励、采样、估计和有效性判断分层；
- 优先离线拟合，稳定后再考虑在线辨识；
- 保存原始波形和拟合残差，不只输出一个参数；
- 用不同幅值和方向重复，给出置信范围或离散程度。

空载条件下电气参数和磁链具有较高可行性；机械参数只能作为特定空载装配的近似，不能等同于带载模型。

建议退出条件：

- 参数单位、符号和坐标定义明确；
- 多次估计具有可接受的一致性；
- 参数能预测至少一组未参与拟合的响应；
- 结果能够被后续控制器设计直接使用。

## 阶段 2：三环系统化设计与自整定

目标：形成“辨识—计算—实验—评价”的闭环，而不是只保存一组手调 PI。

电流环：

- 依据 Rs、Ld/Lq、采样和计算延迟选择目标带宽；
- 计算 PI 和积分限幅；
- 验证电流阶跃、交叉耦合、饱和与参数误差；
- 比较手调参数与模型设计参数。

2026-08-24 已完成离线审计、首轮 A/B 和 0.75–2.25 kHz 扩展网格。扩展实验两轮共 192 个 d 轴阶跃，无运行中淘汰；量化感知汇总筛选中 1.25–2.0 kHz 通过，2.0 kHz 以平均 131.5 µs 上升时间和 6.99% 最大超调成为频响候选。2.25 kHz 更快但正负聚合差和零点噪声略过门槛。随后闭环频响已验证 1.5–2.25 kHz 均具有 77.4° 以上相位裕量，联合规则选择 2.0 kHz 进入前馈组合；现役参数继续作为默认值。

闭环频响硬件已经完成：5 组 × 16 频点全部有效，1.5/1.75/2.0/2.25 kHz 的相位裕量约 84.5°/82.2°/79.6°/77.4°。结合阶跃筛选，2.0 kHz 成为联合候选；2.25 kHz 只作边界点。随后双顺序正反旋转组合验证表明，2.0 kHz 的 q 轴与速度误差没有一致改善，而旋转 id 误差在两轮和 40 kHz scope 中都高于现役。因此“2.0 kHz 不写回、现役 PI 暂时保留”仍是有效实验结论，但它没有完成面向新电机的冷启动自整定：既有流程依赖现役 PI 作比较基线，也只搜索了固定 `Ki/Kp=Rs/L` 的一维带宽族。阶段 2 暂不进入速度环整定，先按 [电流环主机监督式自整定规范](CURRENT_LOOP_AUTOTUNING.md) 完成不依赖旧 PI 的闭环。

电流环 v1.0 以阶段 1 参数和硬件约束生成 R-L 安全初值，再用实测对象按交越频率与相位裕量修正；D-027～D-031 的失败、门槛修正和现役对照作为历史证据保留。D-032 的 421 点最终局部筛选选出 `measured_fc0925_pm80`，75 点独立留出以 969.5 Hz 鲁棒带宽、78.81° PM 和 11.90% 方向差再次通过全部 D-029 门槛；d/q 分轴 PI 已写入默认源码，当前电流环候选搜索结束。

速度环：

- D-033 的 [速度环经验自整定规范](SPEED_LOOP_AUTOTUNING.md)、最小固件接口和首批主机筛选器作为已完成的离线工作保留，但硬件候选筛选暂停；
- D-034 新增 [ABZ 编码器角度与速度估算评估规范](ENCODER_SPEED_ESTIMATION.md)：先修正 `CNT/(ARR+1)` 角度归一化，再比较当前矩形窗、短窗+IIR、M/T 和编码器 PLL；
- 当前 500 点/40 kHz 速度估算等价于 12.5 ms 矩形窗，理论 -3 dB 约 35.4 Hz、首个陷波点 80 Hz；既有约 25 Hz 速度闭环结果包含测速器动态，不能单独解释为机械对象上限；
- D-035～D-041 已冻结 WIN、测出历史默认约10.2 Hz闭环并得到高频对象边界；D-042 保留“没有候选通过全部频域门槛”的原始结论；
- D-043 的32份阶跃和四次正反4000 rpm斜坡已经闭合。`fc24_pm70` 最大超调7.44%、最坏整定86.75 ms，斜坡平均/最坏RMS误差23.90/47.09 rpm，均优于历史默认；它已写为约45–55 Hz速度闭环的复位默认，速度 PI搜索结束；
- 原 `190 Hz` 只保留为电流环/执行频率推导的设计上限，新的速度环护栏还必须受实测测速器幅相约束。

位置环：

- 按 [位置环高效整定规范](POSITION_LOOP_TUNING.md) 使用串级运动学关系直接生成4/6/8/10 Hz四组P候选，不辨识J/B，也不做大规模扫频；
- 先加入运行时位置PID和位置输出速度限幅，以一次反序连续实验比较历史默认与四候选；
- 只用稳定性、超调/整定、稳态误差和安全四类量化结果选择参数，再做一轮轨迹冒烟。
- D-044～D-047已停止全局P、前馈和加速度网格；当前最佳实验轨迹为
  `TRAP 180 deg/s, 900 deg/s², FF ON`，但小行程仍有机械位置/方向相关过冲；
- D-048按 [零速位置伺服诊断方案](ZERO_SPEED_POSITION_SERVO.md) 先比较低速跟踪、正反
  接近和多角度保持电流，只在周期性可重复时进入齿槽补偿。
- D-049纯速度交叉已经确认bw20低速纹波更差，保持WIN+D-043 fc24，不做低速增益调度
  或M/T开发；其位置记录因D-051发现的双重轨迹混杂而撤回。
- D-051按 [小行程位置端点重复性验证](POSITION_ENDPOINT_REPEATABILITY.md) 完成六区域48段
  A/B。内速度 `TRACK STEP`使合格数1→32并令稳态误差48/48通过；`START POSITION`现于
  固件自动清除内速度轨迹。
- D-053按 [位置默认配置代表区域A/B](POSITION_DEFAULT_AB.md) 只取0°动态、120°静态和
  240°对照区域，比较当前默认 `RAMP 180 + FF OFF` 与候选 `TRAP 180/900 + FF ON`。
  D-053未满足默认升级规则；D-054固定TRAP的FF OFF/ON进一步确认全前馈改善整定、但
  不改变约2.2°最坏区域过冲。默认保留RAMP+FF OFF，TRAP+FF ON作为可选快速轨迹；
  位置环在当前空载边界下闭合，不再扩大P、轨迹、速度PI或位置补偿网格。

自整定不追求“一键万能”。第一版固定为主机监督式工具：Python 自动生成候选、编排激励、拟合和评价，STM32 只执行实时控制与测量；候选运行时下发，推荐参数由用户确认后才允许写入默认固件。在线 MCU 全自动整定只有在安全边界和有效性判断成熟后再考虑。

建议退出条件：

- 参数计算过程可解释且可复现；
- 不依赖已有 PI 生成参数，并在预定义绝对门槛下给出推荐或明确失败；
- 三环带宽关系、限幅和饱和行为有数据支持；
- 失败时能安全回到零输出，而非堆叠复杂预测性防御。

## 阶段 3：解耦、前馈与电压约束

目标：把现有 dq 交叉耦合和反电动势前馈从“代码存在”提升为“参数正确、收益可量化”。

本阶段以 [阶段3研究大纲](STAGE3_DECOUPLING_AND_VOLTAGE.md) 为工作入口，优先回答三个问题：

1. 当前坐标、符号、单位和时序下，交叉耦合项与反电动势项是否分别正确；
2. 它们能否重复降低跨轴电流误差或反馈PI电压负担，而不恶化主轴跟踪；
3. 接近电压边界时，矢量限幅、PI tracking和前馈是否能平稳协同并从饱和恢复。

源码和历史数据离线复算、OFF/CROSS/BEMF/BOTH最小接口及D-057硬件分项矩阵已经完成。BEMF实测坐标与理论一比一并主导PI电压减负；CROSS q轴可观测，且局部阶跃跨方向重复改善dq跟踪。D-058三批共24份Scope又把证据扩展到0.22人工电压上限：两批40 kHz短窗证明限幅进入，4 kHz/1.024 s长窗证明OFF/BOTH均回到脉冲前速度、电流和PI状态。D-059按阶段1模型证据和D-057/D-058直接基线将源码默认更新为IDENTIFIED+BOTH，烧录后的复位模式、正反前馈符号和安全停止均通过。阶段3退出条件已满足，不再扩饱和或模型网格。

空载下适合验证高速电流跟踪、模型符号、PI负担、电压裕量和饱和恢复，但不能证明带载扰动抑制、效率或转矩能力。母线纹波补偿可先完成软件链路与低频一致性审计；没有可控母线扰动时不强行给出动态收益结论。

建议退出条件：

- 分项公式与坐标约定通过离线复算和板端遥测一致性检查；
- 至少一个正反、反序硬件矩阵能将跟踪误差、跨轴误差和控制电压分开评价；
- 电压裕量、限幅占比和恢复过程有原始数据，或者明确记录当前硬件范围内无法触及边界；
- 默认前馈策略只在重复收益超过测量散布时变更，否则保留可切换实验能力；
- 形成阶段4可以直接复用的电压可用量与饱和接口定义。

## 阶段 4：电压/电流约束与弱磁

状态：D-061～D-065 已完成当前空载与人工电压边界内的闭环。完整推导和证据见
[弱磁控制研究](FIELD_WEAKENING_RESEARCH.md)。最终结构为“定子电压闭环成熟基线 +
IDENTIFIED 各向异性电压椭圆前馈优化”：

- 以限幅前请求电压、实际母线和电流圆为约束，生成负 d 轴电流；
- FEEDBACK使用4 kHz电压PI；HYBRID以IDENTIFIED稳态dq电压椭圆前馈工作点并用同一PI校正；
- 5 A总dq电流圆在速度PI运行前动态更新q轴输出限幅，保持其内部anti-windup一致；
- 复用现有 `id_ref`、`ud/uq` 和 `voltage_scale`，未增加 Scope 通道；
- 不重新整定三环 PI，不加入 MTPV、过调制、MPC 或无证据的多层 q 轴回退。

最终参数为95%电压目标、200 Hz请求电压低通、`Kp=0.4 A/V`、
`Ki=2400 A/(V*s)`、`id_ref`斜率500 A/s。0.35人工比例下±5000 rpm主矩阵与0.45比例下
±6500 rpm扩展矩阵各完成12份双向反序Scope，资格检查均64/64通过。HYBRID相对FEEDBACK
在5000/6500 rpm把实际dq峰值从4.713/5.416 A降到3.984/4.131 A，而电压误差RMS保持
相当；复位默认因此冻结为IDENTIFIED+BOTH+HYBRID。

D-065补齐动态边界：固定±6500 rpm时在单次Scope内执行`VOLT LIMIT 1.00→0.45→1.00`，
FEEDBACK/HYBRID双向共4次访问、44/44检查通过，最长弱磁进入/退出为4.25/10.25 ms，
电压和速度跟踪保持在D-064水平。阶段4不再追加人工比例、速度或高级算法网格。

MTPA 从当前主动路线延期。现有空载条件可以验证 MTPA 公式和轨迹，却不能验证同转矩最小
电流、轴功率或效率收益；继续实现只会增加与弱磁电流分配的耦合而没有可闭环的评价量。
获得可控负载或转矩/功率测量后，再把 MTPA 作为独立研究阶段恢复。

阶段退出边界：这些空载结果验证了人工电压边界下的电压利用率、负 d 轴电流、速度扩展、
电流圆和退出恢复，但不能代表自然母线基速、带载恒功率、效率或永磁体退磁安全边界。
没有新证据时不追加Ld调度、MTPV或更高速度网格，下一主线进入阶段5方案讨论。

## 阶段 5：无感控制

目标：利用现有编码器作为参考真值，定量研究估计角度和速度。

候选路线：

- 中高速：反电动势、磁链或滑模观测器；
- 低速：高频注入或混合估计；
- 启动：对准、开环加速、闭环接管；
- 全速域：多观测器切换、失锁判断和降级；
- 鲁棒性：Rs、L、磁链误差和母线波动敏感性。

每一步应同时记录编码器角度和估计角度，报告误差分布、相位延迟、速度范围和失效条件。无物理示波器仍可开展控制算法研究，但硬件注入波形、开关噪声耦合和功率级问题只能有限判断。

## 阶段 6：方向化完善与项目表达

机器人控制分支：

- 位置轨迹与跟踪误差；
- 低速和反向平稳性；
- 摩擦、齿槽转矩和扰动补偿；
- 扰动观测器或扩张状态观测器；
- 机械装配变化下的鲁棒性。

新能源电驱分支：

- 参数辨识与参数漂移；
- 快速转矩/电流响应；
- 弱磁、电压饱和和电流约束；MTPA待受控负载/转矩功率测量具备后恢复；
- 无感控制与模式切换；
- 故障状态管理和约束控制。

最终展示应包含：

- 系统结构和硬件边界；
- 一条完整的算法推导—实现—测试案例；
- 自动化实验和软件示波器；
- 基线与优化后的量化对比；
- 失败案例、限制和下一步，而不是只展示电机能转。

## 当前条件下的可行性

| 方向 | 可行性 | 当前边界 |
|---|---|---|
| 三环与自动化评价 | 高 | 空载性能 |
| Rs、Ld/Lq、磁链辨识 | 较高 | 温升和大电流范围有限 |
| 惯量、摩擦辨识 | 中 | 只代表当前空载机械系统 |
| PI 设计与自整定 | 高 | 扰动/带载验证有限 |
| 解耦、前馈、电压约束 | 高 | 负载收益难完整评价 |
| 弱磁速度扩展 | 较高 | 不能证明带载恒功率 |
| MTPA | 延期 | 缺少受控转矩/轴功率，当前无法验证最小电流或效率收益 |
| 中高速无感 | 较高 | 以编码器为参考，空载为主 |
| 低速 HFI | 中 | 注入噪声和硬件带宽待实测 |
| 效率/转矩地图、热验证 | 低 | 缺少测功、负载和温度测量 |
| 栅极/开关波形验证 | 不具备 | 缺少物理示波器 |

## 路线调整规则

- 新阶段不是以“代码写完”为完成，而是以实验证据和可复现性为准。
- 出现基础稳定性问题时允许回退，不把回退视为路线失败。
- 算法收益在当前硬件条件下无法验证时，可以保留实现和仿真，但必须明确标注未完成硬件验证。
- 每次只选择一个主要研究问题，测试基础设施只按它的需要扩展。
- 路线变化记录在 docs/DECISIONS.md；本文件保持能力层面的中长期视角。

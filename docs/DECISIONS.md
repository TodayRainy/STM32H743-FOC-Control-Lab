## D-014：阶段 1 只辨识基本 dq 电气模型

- 日期：2026-08-24
- 状态：采用
- 决定：保留现有 Rs、Ld、Lq、Ls、Lq-Ld 和永磁磁链参数种类；Rs 同时估计逆变器等效压降，Ke/Kt 由磁链派生。当前不辨识 J、B、库仑摩擦、温度系数或饱和图谱。
- 原因：当前只有 24 V 限流电源、空载电机和软件观测。基本电气参数能够直接服务电流环、dq 解耦和反电动势前馈；机械参数和饱和图谱在缺少转矩与温度基准时容易产生没有工程意义的数字。
- 方法来源：参考 ODrive 的限流校准和带宽参数化、VESC 的功率约束与多证据链、moteus 的原始数据/质量指标以及 NXP MID 的交流注入方法；仅吸收方法并在本项目中独立实现，不复制外部工程代码。
- 输出规则：Ld/Lq 只有在轴间差异显著高于重复测量不确定度时分别采用，否则控制器使用等效 Ls，并记录“凸极差异不可可靠分辨”。
- 复核条件：基本参数通过重复和留出工况验证，且后续 MTPA、弱磁或速度环自整定明确需要更丰富模型时再扩展。

## D-015：阶段 1 使用 3 A 分级 RL 激励，辨识结果验证后再写回控制器

- 日期：2026-08-24
- 状态：采用
- 决定：ProDrone 3505 的首个有效 RL 工况使用 ±1/±2/±3 A 六点激励，辨识专用中止阈值为 5 A；不按电机旋转额定电流直接提高静止注入电流。辨识结果先作为候选模型参数保存，不自动覆盖当前 PI 和前馈参数。
- 原因：当前采样理论量程约 ±55 A，3 A 已能显著提高电阻回归信噪比；实测正常 RL 峰值相电流 2.874 A，且 500 Hz 电感注入电流 RMS 约 1.0–1.17 A。静止注入缺少旋转风冷，所需电流应由信噪比、拟合残差和重复性决定，而不是追求电机额定电流。
- 证据：三次 Ld 极差约 0.085%，Lq 极差约 0.64%；两次磁链相差约 0.012%。Rs 后两次相差 0.62%，但第一次与 Voff 联合偏离，因此绝对 Rs 尚需六点原始值、温度和留出电压预测复核。
- 复核条件：若点级残差表明 3 A 范围仍不足以分离 Rs 与逆变器非线性，可在确认绕组温升、功率级和供电裕量后增加一个更高但短时的电流档；否则不再提高。

## D-016：优先增加独立验证信息，不增加默认辨识电流

- 日期：2026-08-24
- 状态：采用，已完成硬件验证
- 决定：保持 3 A RL 目标和 5 A 中止阈值。Rs 使用相反顺序的两次扫描并以 ±1.5/±2.5 A 留出；Ld/Lq 比较 0.25/0.35 V 两个注入幅值；磁链继续用原四点拟合，以 ±2000 electrical rad/s 两点留出。
- 原因：现有 Ld/Lq 和磁链重复波动已经远小于参数差异，继续增加同类拟合点或电流只能降低表面统计波动，不能证明模型外推能力。Rs 的主要问题是与 Voff、时间/温度漂移的可分离性，需要点级残差和顺序对照。
- 模型换算：主机报告按 `Kv = 60/(2π√3·pole_pairs·flux)` 输出当前 SVPWM 线性母线利用假设下的无载模型 KV，并输出 `Kt = 1.5·pole_pairs·flux`；必须连同 Clarke/Park 与峰值/RMS 约定解释，不能直接当作铭牌复测。
- 验证结果：修正采样方法后，两次 Rs 正反扫差为 0.650%/0.092%，拟合 RMSE 6.04/6.71 mV，留出 RMSE 8.51/9.11 mV；Ld/Lq 双幅值差均小于 1.2%。磁链拟合 RMSE 1.48 mV、留出 RMSE 2.87 mV、最大误差 3.52 mV，模型 KV 较铭牌低 6.6%。全部预定义筛选线通过。
- 复核条件：若后续温度或 A/B 控制实验显示模型误差成为主要限制，再讨论温度补偿或更高电流短时档；否则不提高。

## D-017：Rs 使用转子 d 轴持续调压采样

- 日期：2026-08-24
- 状态：采用
- 决定：自由转子条件下，Rs 直流激励沿编码器实测转子 d 轴注入；在电流收敛、稳定等待和平均采样期间持续调压，并用实际施加电压与实际平均电流拟合。
- 原因：固定定子轴注入会随转子位置产生 q 轴转矩；只在收敛阶段调压会使等待和平均期间的电流漂离目标。诊断版重复运行曾出现 1 A 目标只达到 0.628 A、正反 Rs 差 8.85%、Voff 差 32.27 mV。修正后 16 个电流点准确到达目标附近，连续两次全部质量指标通过。
- 边界：该方法依赖当前编码器角度可用；未来无感或无位置传感器辨识需要另行设计转子锁定/角度搜索方法，不能直接删除角度依赖。
- 复核条件：更换电机、编码器或逆变器后，先检查实际 I/U 点、转子运动和正反扫一致性，再决定是否调整调节速度或稳定时间。

## D-018：辨识模型先只进入可切换前馈 A/B

- 日期：2026-08-24
- 状态：采用，硬件 A/B 已完成
- 决定：保留原 PI、速度环和观测器参数不变，仅允许在 READY 下切换 dq 解耦/反电动势前馈使用的 LEGACY 与 IDENTIFIED Ld/Lq/flux。首轮 A/B 同时保留前馈关闭基线。
- 原因：原参数到辨识参数会使按模型计算的电流 PI 同时发生较大变化；直接替换无法区分模型精度、前馈收益和 PI 增益变化。先固定 PI 能把因果关系限制在前馈模型本身。
- 激励：速度环继续控制 q 轴转矩，实验接口只叠加限于 ±1.5 A 的 d 轴电流；首轮使用 ±1500/±3000 rpm、0/±1 A，正反速度和正负电流用于分离固定偏置与模型项。
- 指标：比较 dq 电流误差、`Uqd-current_feedforward` 得到的 PI 补偿电压、前馈公式复算残差和电压限幅比例。空载下若差异接近噪声，不放大结论，也不立即提高电流。
- 验证结果：首轮 12 点平均 PI 电压为前馈关闭 2.189 V、LEGACY 0.291 V、IDENTIFIED 0.306 V；反顺序高速复测后，两轮 ±3000 rpm、±1 A 合并平均为 LEGACY 0.394 V、IDENTIFIED 0.407 V。同一模型重复波动大于两模型均值差，不能可靠区分二者。前馈公式复算残差小于 0.2 µV，证明切换命令和固件公式实际生效。
- 复核条件：PI 参数仍需单独按带宽目标设计和验证；只有出现更高可观测性的带载、瞬态或电压受限实验条件时，再重新比较两组 Ld/Lq 前馈。

## D-019：LEGACY 继续作为前馈默认值，但不解释为物理参数更准确

- 日期：2026-08-24
- 状态：采用
- 决定：复位后的 dq 前馈模型继续默认 LEGACY，IDENTIFIED 保留为可切换候选。阶段 1 不自动写回基础 PI、观测器或默认前馈参数。
- 原因：前馈开启相对关闭把平均 PI 电压负担降低约 86%，收益明确；但 LEGACY/IDENTIFIED 的闭环差异只有约 3%，小于重复波动。保持默认值是避免无证据变更稳定基线，不代表旧 Ld/Lq 的物理辨识精度更高。
- 参数解释：IDENTIFIED Ld/Lq 是 500 Hz、0.25 V 小信号注入下重复和幅值一致性均通过的候选；当前空载稳态前馈主要由几乎相同的磁链项主导，L 项差异仅产生几十毫伏，易被逆变器非线性、损耗和电流噪声掩盖。
- 后续：阶段 2 使用 Rs/Ld/Lq 候选计算 PI 时，先明确连续域公式、离散实现和延迟，再通过电流阶跃独立验证；不能用本次前馈 A/B 代替 PI 设计证据。

## D-020：阶段 2 从保守带宽的 d 轴电流阶跃开始

- 日期：2026-08-24
- 状态：采用，首轮硬件验证已完成，后续由 D-021 至 D-025 演进
- 决定：电流环使用并联 PI 模型 `Kp=2πfcL`、`Ki=2πfcRs` 分别计算 d/q 比例增益；首个硬件候选为 1 kHz，若超调、整定和峰值指标通过，再比较 1.5 kHz。2 kHz 只保留为离线参考，不进入首轮硬件序列。
- 原因：FOC 为 40 kHz，但从 ADC 采样到 PWM 生效的等效延迟尚未实测，离线按 1–2 个周期包络处理；阶段 1 也未能通过空载前馈 A/B 区分旧/新电感。1 kHz 在两组参数、两种延迟下的最坏预测超调约 14.8%，比 1.5 kHz 的 21.9% 更适合作为安全起点。
- 实验边界：自由转子下长 q 轴阶跃会产生转矩和转速变化，首轮连续实验只执行 ±0.5/±1/±2 A d 轴阶跃。q 轴在 d 轴结论通过后采用短脉冲或速度受控方案，不能用 d 轴结果直接宣称 q 轴已验证。
- 保持项：现役 PI、观测器、默认 LEGACY 前馈和 PI tracking 均不自动替换；脚本退出时恢复现役 PI、清零参考并 STOP。
- 复核条件：硬件阶跃若显示 1 kHz 明显过慢且裕量充分，可进入 1.5 kHz；若结果与 R-L 预测不一致，优先检查实际延迟、采样/电压偏置和参数频率依赖，不直接继续提高带宽。

## D-021：1.5 kHz 作为电流环候选，但暂不写回默认参数

- 日期：2026-08-24
- 状态：采用，已完成首轮硬件验证
- 决定：1.5 kHz 模型 PI 成为静止 d 轴首选候选；现役 PI 仍为复位默认值。下一次先验证 1.5 kHz d/q PI 与 IDENTIFIED dq 前馈的组合，不单独永久写回任一轴。
- d 轴证据：两轮正/反顺序共 12 点/配置。±1/±2 A 平均上升时间为现役 312.5 µs、1 kHz 359.4 µs、1.5 kHz 215.6 µs；平均超调为 9.12%/7.77%/8.27%。1.5 kHz 明显更快且未付出可见超调或峰值电流代价。
- q 轴边界：自由转子上的首个 +0.5 A、目标 5 ms q 轴脉冲记录到约 930.7 rpm，触发 500 rpm 中止并 STOP。当前条件不能安全、独立地测量 q 轴阶跃，不能以降低脉冲幅值反复逼近来替代机械约束。
- 旋转验证：在前馈关闭、±1500/±3000 rpm 下三组 PI 都稳定且无电压饱和；高速合并 iq 误差 RMS 为现役 0.122 A、1.5 kHz 0.127 A，差异很小；id RMS 为 0.195/0.245 A，说明较低候选 Kp_d 在高速交叉耦合下尚未显示优势。
- 原因：静止阶跃证明了局部瞬态收益，但高速无前馈工况和直接 q 轴可观测性不足以支持一次性替换 d/q。阶段 1 已证明前馈可把 PI 电压负担降低约 86%，因此组合验证比继续做自由 q 脉冲更有控制意义。
- 复核条件：若最终带宽优胜者 + IDENTIFIED 前馈在正反高速下同时改善或保持 iq/id 误差、速度动态和电压裕量，再讨论写回；否则考虑混合增益或保留现役 PI。直接进入 1.5 kHz 组合验证的顺序已由 D-022 调整。

## D-022：写回前扩大电流环带宽与电流点筛选

- 日期：2026-08-24
- 状态：采用，硬件网格已完整执行

## D-034：速度 PI 整定前先冻结 ABZ 速度估算器

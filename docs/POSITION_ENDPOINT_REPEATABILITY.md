# 小行程位置端点重复性验证

本文冻结 D-051。D-049 已确认现役 WIN 与 D-043 fc24 速度 PI 应保留；本轮不再扫描
测速器、速度 PI、位置 P、轨迹速度或加速度，只回答剩余端点问题是否随机械区域稳定重复。

## 固定配置与矩阵

- WIN 测速器、D-043 fc24 速度 PI、p6 位置 P；内速度参考固定 `TRACK STEP`，避免与
  外层位置轨迹重复限速；
- `TRAP 180 deg/s, 900 deg/s²`，位置速度前馈 ON；
- 以每次 START 时的位置为原点，访问 `0/60/120/180/240/300°` 六个相对机械区域；
- 每个区域执行两轮四个有效转换：第一轮 `0→+10→0→-10→0`，第二轮反序；
- 共 48 个有效小行程，每个方向和回零转换在同一区域重复两次；每段记录2.5 s，区域
  预定位也额外保持2.5 s，避免前一段未恢复而污染下一段。

## 标准

单个端点只看三项，沿用既有位置轨迹标准：

1. 端点过冲不超过 0.5°；
2. 轨迹参考到达后 200 ms 内进入并保持在 ±0.2°；
3. 末段绝对稳态误差不超过 0.2°。

同时用 ABZ 原始电角度的 20 ms 差分报告末段真实速度纹波，但不再增加第四项硬门槛。
同一区域、同一转换的两次结果用于估计重复噪声；不同区域的差异只有明显大于这一重复
噪声时，才解释为机械位置依赖。若重复性仍不足，则停止齿槽或位置补偿设想，不从单次
好坏点拟合补偿表。

## 边界与退出

- `iq_ref` 限幅 4 A，实际 dq 超过 5 A、速度超过 250 rpm或电压缩放低于 0.98即中止；
- 正常或异常退出都 STOP/READY，并恢复 WIN、D-043速度PI、p6、位置前馈OFF和默认RAMP；
- 本轮只适用于24 V空载自由转子，不报告带载定位刚度或保持转矩；
- 若差异可重复，下一步只针对最差/最好两个区域分析端点时序；若不可重复，位置环研究
  在当前硬件条件下收尾，不继续扩大网格。

运行入口：

~~~powershell
python tests/stage2_position_endpoint_repeatability.py --plan-only
python -m unittest tests.test_stage2_position_endpoint_repeatability -v
python tests/stage2_position_endpoint_repeatability.py --port COM_PORT
~~~

## D-051结果

首个1 s预运行显示位置参考坐标正确，但某段未恢复时会污染下一段；该文件
`tests/results/stage2_position_endpoint_repeatability_20260827_201347.json`只作为调整记录
长度的证据。正式2.5 s矩阵随后发现更直接的状态混杂：位置模式继承了此前速度实验留下的
`TRACK RAMP 100`，使位置梯形轨迹输出又经过一次速度斜坡。该组只有1/48段通过，最大
过冲47.43°、最大稳态误差36.93°，不用于机械位置结论。

所有位置入口显式加入 `TRACK STEP` 后，以完全相同的48段矩阵复测：

| 指标 | 遗留速度RAMP | 内速度STEP |
|---|---:|---:|
| 合格段 | 1/48 | 32/48 |
| 过冲门槛通过 | 1/48 | 34/48 |
| 200 ms整定通过 | 1/48 | 41/48 |
| 稳态误差门槛通过 | 19/48 | 48/48 |
| 最大端点过冲 | 47.43° | 1.78° |
| 最大绝对稳态误差 | 36.93° | 0.036° |
| 最坏保持速度纹波 | 15.72 rpm | 0.87 rpm |
| 最大过冲重复差 | 40.61° | 0.264° |

STEP组峰值 `iq_ref=0.479 A`、实际dq `0.724 A`、速度44.81 rpm，电压缩放始终为1，
最终READY并恢复默认。0/60/120/180/240/300°六区域分别通过5/4/4/5/8/6段；回零
`+10→0`为12/12，`-10→0`为8/12，而离零 `0→+10`和 `0→-10`分别为8/12和4/12。
稳态保持已经解决，剩余失败集中于可重复的方向/区域相关过冲和少数整定超时。

原始端点时序还把剩余失败分成两类。0°/180°的正向10°动作在位置参考到达时仍沿原方向
运动约6.4–11.3 rpm，而速度命令已经接近零或反向，属于动态制动滞后；120°/300°的
部分负向动作则已接近0 rpm，却停在目标外0.67–1.37°，此时控制器已给出约3.1–7.5 rpm
反向纠偏命令和0.15–0.34 A纠偏电流，更像位置相关静摩擦/齿槽锁定。两类问题不能通过
一次全局P调整同时解决；若继续，只各取一个代表区域分别研究制动轨迹与最小纠偏转矩。

固件现于 `START POSITION` 自动把内速度轨迹设为NONE，避免普通调用者继承速度模式状态。
Keil构建0 error/0 warning，Flash 109,464 B、RAM 221,092 B；固定J-Link V7.54d烧录
Program & Verify O.K.并完成故意预置RAMP的冒烟。机器摘要为
`tests/baselines/stage2_position_endpoint_repeatability_d051_20260827.json`。

后续D-052已把内速度轨迹清除写入位置启动入口；D-053/D-054完成默认配置选择并停止位置
参数搜索。本文中“若继续”的代表区域建议已经由
[`POSITION_DEFAULT_AB.md`](POSITION_DEFAULT_AB.md)执行并取代，不再作为当前待办。

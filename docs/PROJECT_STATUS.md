## 当前已知问题与不确定项

1. 首次进入位置模式后的 +2° 小阶跃出现过明显极限环，原因尚未定位。候选方向包括状态切换、位置/速度环积分初值、摩擦和量化、环路带宽配合。
2. 正负小电流阶跃的峰值、上升时间不完全对称，需要重复性测试后再判断是采样噪声、坐标/电流偏置还是控制差异。

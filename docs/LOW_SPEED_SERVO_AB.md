# 低速速度伺服交叉诊断

本文冻结 D-049 的最小实验。D-048已经证明位置保持样本被真实转子往复运动污染；本轮
只区分“测速器影响”“速度PI影响”和两者的交互，不重新整定位置环，也不开发新测速器。

## 因子与工况

使用现有固件的三种ABZ测速器与两组已有硬件证据的速度PI组成完整 `3×2` 矩阵：

| 因子 | 水平 |
|---|---|
| 测速器 | BASE 12.5 ms窗口、WIN 1 ms+150 Hz、PLL 200 Hz |
| 速度PI | 现役D-043约50 Hz、D-040已验证约20 Hz |

每组依次执行：

1. 速度模式 `+5/+10/+20/0/-5/-10/-20/0 rpm`，每段2 s；
2. 位置模式固定p6、`TRAP 180/900`、前馈ON，执行 `+10/0/-10/0°`，每段保持2.5 s；
3. STOP并回到READY后再切换下一组。

总计48个低速段和24个长保持段，不再扫描一圈机械位置。配置顺序采用
`WIN50→BASE50→PLL50→PLL20→BASE20→WIN20`，让同一PI内测速器完整覆盖，并使两个PI
的访问方向相反，减小固定顺序偏差。

## 评价量与解释

主评价量不是当前选中测速器的输出，而是从ABZ原始电角度展开后用20 ms位置差分得到的
机械速度。每组报告：

- 低速实际速度的均值误差和纹波；
- 选中测速器自身的速度纹波，用于判断估算值与真实运动的差别；
- 长保持末1 s的实际速度纹波、位置平均误差和位置纹波；
- `iq_ref` RMS及安全峰值。

本轮不设置复杂综合评分，只做同因子对照：同一测速器比较50/20 Hz PI，同一PI比较三种
测速器。只有某一变化同时降低低速实际运动纹波和位置保持运动，才认为它有工程收益。
若纯速度模式改善而位置保持不改善，再检查位置P；若PI影响占主导，研究低速增益调度；
若测速器影响占主导，研究低速测速切换；六组均无明显改善时，才进入M/T混合测速实现。

## 边界与安全

- 不修改测速器参数、PI默认值或测试矩阵；D-049首次预运行暴露STOP后测速器状态未清零，
  必须先烧录D-050启动状态修复固件；
- 本轮不重新建立齿槽图谱，也不以空载数据宣称保持转矩；
- 沿用4 A `iq_ref`、5 A实际dq、250 rpm和98%电压利用率边界；
- 正常或异常退出均STOP/READY，并恢复WIN、D-043速度PI、位置前馈OFF和默认RAMP；
- 实际运行需要24 V，电机会双向低速旋转并做小角度往复；每批运行前重新确认安全状态。

## D-049 首次预运行与D-050前置修复

首次预运行在进入第一组后约2 s即因遥测速度越过250 rpm中止，没有形成任何有效低速或
位置记录。随后STOP已人工补发并确认READY。READY下WIN保持在-229.7 rpm，但连续3 s的
ABZ原始角度差分严格为0 rpm，证明这是冻结的旧测速状态，不是转子仍在旋转。

首个根因是 `foc_motor::clear()` 只清控制器，没有清ABZ/绝对编码器的 `foc_speed` 状态；
第二个根因是READY期间不更新角度，转子惯性滑行会在下次START被误算成单周期位移。
D-050在电机CLEAR时先用当前编码器角度同步历史，再清空测速器，并让
`foc_speed::clear()`同步把对外速度置零。主机异常恢复也改为用READY和dq电流确认STOP，
不再让READY下冻结的速度字段阻断默认恢复。原矩阵和评价标准不变，首次中止文件
`tests/results/stage2_low_speed_servo_ab_20260827_194912.json`不作控制性能证据。

D-050首版仅清滤波状态的冒烟仍失败：首次ABZ校准结束后转子带约160 rpm惯性速度，第二次
START又因READY期间的角度历史断档触发保护；结果见
`tests/results/d050_speed_restart_smoke_20260827_195715.json`。最终修正版加入启动前角度同步，
并让D-049每次进入速度/位置模式后先保持零目标1 s。

## 硬件结果与结论

D-050最终版烧录后，`START零速 → 20 rpm → STOP → START零速`冒烟完整通过。第二次启动
末1 s的ABZ位置差分速度均值为0.18 rpm、纹波0.71 rpm RMS，证明旧测速状态和READY角度
断档均已消除。随后D-049六组、48个速度段和24个位置段全部完成，最终模式17并恢复
WIN、D-043速度PI和默认位置配置。

| 配置 | 最坏非零速度纹波 (rpm RMS) | 最坏位置保持速度纹波 (rpm RMS) | 位置绝对平均误差中位数 (deg) |
|---|---:|---:|---:|
| WIN + fc24 | 11.03 | 7.67 | 0.031 |
| BASE + fc24 | 12.42 | 5.11 | 0.012 |
| PLL + fc24 | 11.02 | 8.20 | 0.060 |
| WIN + bw20 | 19.07 | 25.19 | 20.34 |
| BASE + bw20 | 22.27 | 29.12 | 30.43 |
| PLL + bw20 | 18.91 | 22.57 | 8.08 |

表中低速速度列来自纯速度模式，继续有效；两个位置列是历史原始统计。D-051确认位置阶段
继承了每组速度实验设置的 `TRACK RAMP 100`，与位置梯形形成双重轨迹，因此位置列不再
用于比较测速器或PI，也不能支持低速位置调度。

真实运动由ABZ原始角度20 ms差分得到。纯速度段已经足以说明：降低到bw20在三种测速器
下都显著增加低速纹波，因此不建立低速PI调度。fc24下WIN和PLL的纯速度结果等价；BASE
略差且其持续旋转高频能力已有较差证据。因此默认保持WIN+D-043 fc24，不开发测速切换
或M/T作为当前主线。历史位置列不再参与这一决定。

本批峰值 `iq_ref=0.511 A`、实际dq `0.864 A`、选中测速速度174.61 rpm，电压缩放始终
为1。原始结果为 `tests/results/stage2_low_speed_servo_ab_20260827_200222.json` 与同名CSV，
机器摘要为 `tests/baselines/stage2_low_speed_servo_ab_d049_20260827.json`。下一步回到位置环，
只在少量机械区域复核小行程端点重复性，不再扩大速度PI或测速器网格。

后续状态：上述位置复核已由D-051至D-054完成。低速结果继续支持“不采用bw20调度或新
测速切换”，但本文不再承载当前待办；主线已转入阶段3解耦、反电动势前馈与电压约束。

# 电流环主机监督式自整定规范

本文定义阶段 2 电流环自整定的固定输入、理论方法、实验流程、验收门槛和输出语义。D-027 建立 v1.0；D-028 建立 v1.1，把低频跟踪误差与高频采样纹波分开；D-029 建立 v1.2，把归一化整定硬门槛改为 1.25，并将候选范围扩展到 2 kHz。实现和实验结果不得在本轮结束后反向修改本规范；若门槛或流程确需调整，应先在 `docs/DECISIONS.md` 记录原因和版本，再重新生成对应基线。

## 目标与边界

目标是让一台新电机在完成阶段 1 基本电气参数辨识后，不依赖已有的“可用 PI”，由工具生成、实测和推荐电流环参数。现役 PI 只能在推荐结果冻结后作为留出对照，不得参与候选生成、门槛定义或排序。

v1.0 采用主机监督式自整定：

- STM32 负责 40 kHz 实时 FOC、PI 运算、安全限幅、测试激励和 scope 采样；
- Python 负责读取辨识结果、理论设计、实验编排、频响拟合、候选筛选和报告；
- 候选 PI 通过串口临时写入 RAM，脚本成功或异常退出时恢复安全参数并 STOP；
- 推荐结果先保存为机器可读报告，不自动修改源码、Flash 或掉电保存配置；
- 用户确认推荐结果后，才单独决定是否写入默认固件并重新编译、烧录。

完整自整定算法不放入 MCU。板端后续若增加 q 轴同步正弦等接口，只属于通用、安全的实验激励原语，不在中断内做拟合、搜索或参数选优。

当前只有空载自由转子、24 V/4.5 A 限流电源和软件示波器。v1.0 可以完成静止 d 轴的完整电气验证，并用零均值高频 q 轴激励补充 q 轴证据；不能把这些结果扩展为带载、热稳定或全速域性能结论。

## 输入契约

必需输入为：

- 阶段 1 输出的 `Rs`、`Ld`、`Lq` 及各自重复测量离散程度；
- 电流环采样频率、PWM 更新关系和等效延迟范围；
- 母线电压、PI 输出限制和 SVPWM 可用电压；
- 阶段 1 已验证的最大辨识电流、功率级安全电流和主机硬中止电流；
- PWM 关闭时的电流测量噪声，以及零参考闭环噪声；
- 固定策略 `balanced`。

可选输入为后续外环要求的最低电流环带宽。它只作为性能需求，不作为既有 PI 或经验增益输入。

以下任一情况应停止而不是生成参数：参数非有限或非正、单位/坐标约定不明确、重复辨识离散度未通过阶段 1 门槛、电流极性或电压尺度检查失败。

## 理论初值

静止单轴电气模型为：

~~~text
P(s) = 1 / (L*s + R)
C(s) = Kp + Ki/s
~~~

令 PI 零点抵消 R-L 极点：

~~~text
Ki/Kp = R/L
Kp = wc*L
Ki = wc*R
~~~

其中 `wc=2*pi*fc`。在理想连续模型下，闭环退化为带宽 `fc` 的一阶系统。d/q 轴分别使用 Ld/Lq，因此允许不同 Kp；同一 Rs 和目标带宽下 Ki 相同。

初始带宽不得只由用户随意指定。工具先由以下约束计算保守上界：

- 采样约束：候选交越频率不得高于 FOC 频率的 1/10；
- 延迟约束：按 `f_delay=(pi/2-PM_min)/(2*pi*Td_max)` 计算，其中 `PM_min=60°`；
- 电压约束：两轴分别满足 `2*pi*fc*L*delta_I + Rs*I_peak <= 0.8*Vdq_available`，保留 20% 电压裕量；
- 电流约束：离散 R-L/延迟包络仿真的预测峰值不得超过主机硬中止电流的 80%。

记上述约束的最小上界为 `f_upper`，初始带宽固定取 `f_seed=min(0.02*FocSampleHz, 0.5*f_upper)`。低电流验证依次尝试 `f_seed`、`0.5*f_seed` 和 `0.25*f_seed`；连续三档仍失败则输出 `seed_failed`，优先复核辨识、极性、采样延迟和电压尺度，不继续搜索高增益候选。

## 实测对象与第二级设计

安全初始控制器通过后，复用同步正弦和 40 kHz scope 测量：

~~~text
T(jw) = I(jw) / Iref(jw)
P(jw) ~= I(jw) / Uactual(jw)
~~~

`P(jw)` 用于描述当前逆变器、采样、计算延迟和电机共同形成的实际对象。`T/(1-T)` 反算只在数值条件良好的频段作为交叉检查；闭环接近 1 时不得用病态反算制造高置信度结论。

第二级候选不直接在四个 PI 增益上做无约束黑箱搜索，而以目标交越频率 `fc` 和目标相位裕量 `PM` 参数化。对实测对象，在交越点构造：

~~~text
C*(jwc) = exp(j*(-180 deg + PM)) / P(jwc)
Kp = real(C*)
Ki = -wc*imag(C*)
~~~

只有 Kp、Ki 均为正且完整频率曲线通过离线稳定性、电压和噪声预筛的候选，才允许进入硬件。候选同时在 Rs/Ld/Lq 重复测量形成的参数包络和等效延迟包络内检查，不只针对单一名义模型。

## 6–8 组真实上板策略

首轮 v1.0 让 8 组新生成的成对 d/q PI 真实上板，不用旧 PI 占用名额：

- 2 组为理想 R-L 设计锚点，带宽分别为 `f_seed` 和 `min(2*f_seed, 0.8*f_upper)`；
- 6 组为实测对象设计点，交越频率取 `0.60*f_upper`、`0.75*f_upper` 和 `0.90*f_upper`，分别配对 65° 和 75° 两个目标相位裕量；
- 重复或未通过离线硬安全预筛的点，用相邻的安全设计点替代，但不得放宽安全门槛凑数；
- 若最终只能形成少于 6 组安全且互不重复的候选，输出 `insufficient_safe_candidates` 并停止硬件批量实验。

首轮结果曾把 v1.1 的局部搜索收敛到 800–1000 Hz。D-029 认为该范围会过早排除已有硬件证据支持的较高带宽，因此 v1.2 固定为 8 组：理想 R-L 极点抵消 800/1250/1500/1750/2000 Hz，以及实测对象 1000/1250/1500 Hz、75° 相位裕量。`f_upper` 仍用于新电机的冷启动种子和保守边界；超过该值的扩展候选只有在安全种子已经测得对象、且完整离线包络预筛通过后才允许上板，不能绕过初值失败状态。

硬件实验分两级，但所有 6–8 组都必须产生真实测量数据。

### 一级粗筛

每组至少执行：

- 零参考噪声采集；
- 正负 d 轴阶跃，幅值为最大验证电流的 25%、50%、75% 和 100%；
- 覆盖低频、预计交越附近和高频侧的紧凑 d 轴频响；
- 峰值 dq 电流、转速、实际电压和电压缩放监控；
- 正常或异常退出后的清零、参数恢复和 STOP。

一级粗筛用于真实淘汰，不用离线仿真替代。运行中的硬保护门槛与最终性能门槛分开，避免单点噪声中止整批实验。

### 二级密集复验

一级结果中最多 3 组进入：

- 完整多频点频响；
- 更密集的多电流点阶跃；
- 带宽升序/降序或候选正序/逆序两轮；
- 正负方向聚合一致性和重复性检查；
- 在具备安全 q 轴零均值激励接口后，执行高频 q 轴补充验证。

最终推荐冻结后，才追加现役 PI 的留出对照。留出对照可以评价工具结果，但不得改变已经冻结的候选门槛和排序方法。

D-029 领先者的独立留出由 D-030 预先固定：只测试已经冻结的 `measured_fc1000_pm75`，使用未参与筛选的 `±1/±2/±2.75 A`，以及 d/q 两轴相同的 80/120/220/410/590/740/850/950/1050/1175/1375/1750/2500/3500 Hz。两轮共 71 份 scope，继续应用全部 D-029 门槛。通过后才进入现役 PI 对照；失败时不修改门槛、不改用本留出数据重新排名。

D-030 通过后的 D-031 对照不再选参。它固定比较推荐参数和现役 PI，两轮交换配置顺序，复用六个留出阶跃，并把两轴频响扩展到板端 `CURRENT SINE` 允许的 4/4.5/5 kHz，以尽量覆盖现役高带宽。推荐参数仍须保持 D-029 绝对合格；现役 PI 不检查候选目标频率、不进入排名。报告直接并列带宽、瞬态、噪声、方向/重复性和控制电压，不合成新的单一分数。

D-031 中推荐参数只因方向一致性重复失去绝对资格。D-032 因此只允许一次局部鲁棒性迭代：实测对象 850/925/1000 Hz × 80°/85° 六组，使用 D-030 点集做两轮 421 点筛选，全部 D-029 门槛保持不变。若有领先者，再以原 D-029 点集做唯一一次 75 点独立留出；无通过者或留出失败后保留现役 PI、结束本轮，不继续扩展候选。

D-032 最终选择 `measured_fc0925_pm80`，且唯一独立留出通过全部门槛。因此该候选成为 v1.2 的最终输出并写入当前电机默认 PI；这项写回来自绝对标准和独立复现，不需要把旧 PI 当作候选基线。

## v1.2 `balanced` 验收门槛

本文的闭环带宽统一指 `T=I/Iref` 相对低频平台下降 3.0103 dB 的频率，不使用绝对 -3 dB。低频平台至少取预计交越频率 1/4 以下的两个点；扫频未覆盖下降交点时记为未测得。

候选必须同时满足：

- 参数不确定性和延迟包络内的最小相位裕量不低于 60°；
- 灵敏度峰值 `Ms=max|1/(1+L)|` 不高于 1.7；
- 理想 R-L 锚点的实测 -3 dB 带宽与目标偏差不超过 ±25%；实测对象候选的环路交越与目标偏差不超过 ±15%，-3 dB 带宽作为实际跟踪性能和最终排序指标；
- 对有效信噪比阶跃，滤波后最大超调不超过 10%；
- 2% 整定时间满足 `t_settle*f_bw<=1.25`；`<=1.0` 记为优秀目标，但不是额外硬门槛；
- 以该候选、该轴、该轮的实测 -3 dB 带宽为分界，带宽内稳态跟踪误差 RMS 不超过 `max(3*PWM 关闭带宽内噪声, 2%*阶跃幅值)`；直流偏差属于带宽内误差；
- 带宽外采样纹波不参与 PI 排名，只要求不超过 `max(2*PWM 关闭带宽外噪声, 2%*最大验证电流)`，用于发现采样或功率级异常；
- 零参考闭环噪声不超过 `max(2*PWM关闭噪声, 1%*最大验证电流)`；
- 正负方向聚合动态差异不超过 15%；
- 两轮聚合重复差异不超过 15%；
- 实验中无电压饱和，电压缩放不低于 0.98；
- 无过流、持续振荡、异常转速、非有限数或安全退出失败。

40 kHz scope 对百微秒上升沿只有少量采样点。上升时间和超调的最终判断使用插值交越和同方向/同轮聚合，不再使用一个采样点变化就可能造成 20% 相对差的逐点最大值；原始逐点结果仍保留。

## 选择与失败语义

先应用全部硬门槛，再按以下固定顺序选择：

1. 取 d/q 两轴、两轮实测 -3 dB 带宽的最小值作为鲁棒闭环带宽；
2. 鲁棒带宽相差不超过 10% 时，相位裕量更高、Ms 更低者优先；
3. 仍接近时，增益更低、带宽外纹波更小者优先。

工具只允许输出：

- `recommended`：d/q 所需证据和全部门槛通过；
- `d_axis_qualified_q_axis_model_based`：d 轴完整通过，q 轴仅有模型或有限高频证据；
- `requirement_not_met`：完成有效实验，但无候选通过全部门槛；
- `insufficient_evidence`：数据质量、频率范围或重复性不足；
- `seed_failed` 或 `insufficient_safe_candidates`：未能安全进入批量测试。

任何失败状态都不自动回退为现役 PI，也不宣称电流环自整定完成。旧 PI 可临时用于恢复已知安全状态，但不改变工具结论。

## 产物和追溯

每次整定至少保存：

- 输入辨识 JSON 和参数不确定性；
- 采样率、延迟、电压、电流和安全边界；
- 全部候选及生成理由；
- 所有上板候选的原始 scope/遥测数据；
- 一级淘汰原因和二级完整指标；
- 最终状态、推荐增益和适用边界；
- 固件 Git 基线、脚本版本和实验时间。

Python 报告是参数推荐的事实来源。源码默认值的修改、编译和烧录属于推荐确认后的独立步骤，不能由自整定脚本隐式执行。

# 位置默认配置代表区域 A/B

本文冻结 D-053。D-052 已消除位置模式继承内速度 RAMP 的双重轨迹问题；本轮不再扫描
位置 P、速度 PI 或测速器，只决定修复后的源码默认位置轨迹是否应从 `RAMP 180 + FF OFF`
升级为当前实验候选 `TRAP 180/900 + FF ON`。

## 矩阵

- 固定 WIN、D-043 fc24、p6，并显式保持内速度轨迹 STEP/NONE；
- 只取 D-051 中三类代表区域：0°动态制动滞后、120°近零速纠偏停滞、240°良好对照；
- 每个区域执行两轮 `0→+10→0→-10→0` 反序访问，每种配置24段，总计48段；
- 默认组按0/120/240°访问，候选组反序访问，降低时间漂移与区域顺序完全重合的风险；
- 每种配置结束都回到同一实验原点再退出位置模式，保证下一配置从相同机械区域开始。

## 标准与解释量

验收只沿用三项：端点过冲不超过0.5°、位置参考到达后200 ms内进入并保持在±0.2°、
末段绝对稳态误差不超过0.2°。不增加新的硬门槛。

为了区分剩余机理，额外记录轨迹参考到达端点瞬间的位置误差、速度命令、选定测速器速度、
ABZ 20 ms差分速度和q轴电流参考。这些量只解释“仍在同向运动的动态制动滞后”与
“已经近零速但纠偏电流不足以立即运动”的差别，不参与事后增加评分项。

候选只有在合格数与三项分项通过数整体不差于默认、且最坏过冲没有恶化时，才进入源码
默认升级讨论。若两者各有优劣，则保留当前源码默认，并分别对0°动态案例和120°静态案例
各做一个单变量诊断，不扩大参数网格。

## 安全与运行

- 24 V空载、转子自由双向运动；脚本不会自动烧录；
- 沿用实际dq 5 A、机械速度250 rpm和电压缩放0.98边界；
- 正常或异常退出均STOP/READY，并恢复 WIN、D-043、p6、`POS FF OFF`、
  `POS TRACK RAMP 180`；
- 结果只支持当前空载系统的默认配置选择，不证明带载刚度或机器人关节扰动能力。

运行入口：

~~~powershell
python tests/stage2_position_default_ab.py --plan-only
python -m unittest tests.test_stage2_position_default_ab -v
python tests/stage2_position_default_ab.py --port COM_PORT
~~~

## D-054：固定TRAP只比较速度前馈

D-053若显示TRAP+全前馈改善参考到点速度和整定、但不能降低最坏过冲，则只追加一个
单变量A/B：两组都固定 `TRAP 180/900`，仅比较位置轨迹速度前馈OFF/ON。机械区域、
两轮顺序、三项门槛和安全边界完全复用D-053，共48段。该批用于判断全前馈是否造成
实际位置领先；不改位置P、速度PI、加速度或测速器。

~~~powershell
python tests/stage2_position_trap_ff_ab.py --plan-only
python -m unittest tests.test_stage2_position_trap_ff_ab -v
python tests/stage2_position_trap_ff_ab.py --port COM_PORT
~~~

## D-053/D-054结果与默认选择

D-053两组各24段完整，最终READY并恢复默认。默认RAMP+FF OFF与候选TRAP+FF ON的
合格数同为8/24；候选把过冲分项12→14、整定分项13→18，峰值实际dq 0.639→0.513 A、
峰值速度78.32→52.93 rpm，但最坏过冲2.070→2.217°，未满足预先冻结的默认升级规则。
两组稳态误差均24/24通过，最大绝对值分别0.045°和0.020°。

D-054固定TRAP后，FF OFF/ON合格数为9/10，过冲分项同为14，整定分项14→20；两者
最坏过冲完全相同为2.217°。全前馈显著降低轨迹到点时的同向速度并改善到位时间，但
不是0°区域过冲的根因；关闭前馈也不能消除该过冲。所有组电压缩放为1，最终READY。

因此源码默认保留 `p6 + RAMP 180 + FF OFF`，不写入TRAP或前馈ON。`TRAP 180/900 +
FF ON`保留为到位更快、峰值速度更低的可选运动轨迹。约2.2°的机械区域相关端点过冲
在四种组合中重复存在，当前无负载和转矩测量条件下不拟合位置补偿表，不继续扩大P、
加速度或前馈网格。机器摘要为
`tests/baselines/stage2_position_default_ab_d053_d054_20260827.json`。

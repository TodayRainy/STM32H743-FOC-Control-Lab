# 阶段3：dq解耦、前馈与电压约束研究大纲

更新时间：2026-08-27

状态：A阶段离线审计完成，B阶段最小接口已构建；等待当次硬件确认后进入C阶段

## 1. 研究目标

阶段3不再扩展三环PI候选，而是把现有dq交叉耦合、永磁反电动势前馈、电压矢量限幅和PI tracking组成一条可解释、可复现的证据链。核心问题只有三个：

1. 公式、坐标、符号、单位和执行时序是否正确；
2. 交叉项与反电动势项分别改善了什么，收益是否超过重复波动；
3. 接近电压边界时，前馈、限幅与积分状态能否协同并平稳恢复。

本阶段服务于后续弱磁和MTPA，但不提前实现完整弱磁或电流轨迹管理。没有负载和测功设备时，只报告空载电流跟踪、电压裕量与约束行为，不宣称带载转矩、效率或恒功率能力。

## 2. 已有事实与固定起点

- FOC/速度/位置控制器执行频率分别为40 kHz/4 kHz/400 Hz。
- 阶段1候选模型为 `Rs=144.818 mΩ`、`Ld=26.044 µH`、`Lq=40.344 µH`、永磁磁链 `0.907950 mWb`；旧模型仍可运行时选择。
- 复位默认采用D-032分轴电流PI、D-037 WIN测速器、D-043速度PI和位置 `p6 + RAMP 180 + FF OFF`。
- 当前电流前馈公式为：

~~~text
uq_ff = omega_e * (flux + Ld * id)
ud_ff = -omega_e * Lq * iq
~~~

- `FF MODE OFF/CROSS/BEMF/BOTH`已实现；`FF ON/OFF`继续作为BOTH/OFF兼容别名，`FF MODEL LEGACY/IDENTIFIED`切换模型。D-059后复位默认为IDENTIFIED、BOTH。
- PI输出与前馈相加后进入 `Vbus/sqrt(3)` 的dq矢量等比例限幅，随后用实际施加电压减去前馈和d轴偏置进行PI tracking。
- 阶段1 A/B中前馈将平均PI电压由2.189 V降至0.291/0.306 V，约降低86%；阶段2组合验证由1.872 V降至0.216 V，约降低88.5%。这证明“总前馈有用”，但LEGACY与IDENTIFIED差异小于重复波动。
- 既有实验全部 `voltage_scale=1`，尚未验证电压饱和占比和退出恢复。
- D-057使用的11通道Scope包含 `id/iq`、参考、电压、角度和速度参考；D-058因快速限幅恢复存在明确可观测缺口，已只在末尾追加 `voltage_scale`形成12通道。36通道遥测仍包含母线、电压缩放和前馈电压。

以上默认与结论只有新证据才改变。瞬时上电、COM号和当前固件状态不属于本文事实。

## 4. 研究问题与候选方法

### 4.1 坐标、符号和单位审计

第一步不接硬件。沿 `电流采样→Clarke/Park→电流PI→前馈→电压限幅→反Park/SVPWM`逐项记录：

- q/d字段顺序、Park正方向和电角速度正方向；
- `Rs/Ld/Lq/flux`是相量、线电压还是其他约定；
- 机械速度、极对数和电角速度的换算；
- 前馈使用实测电流还是参考电流，以及由此引入的噪声/滞后；
- ADC采样到PWM生效的离散时序；
- 限幅后PI tracking是否保持“总施加电压减去前馈”的一致坐标。

用既有CSV/Scope离线重算 `ud_ff/uq_ff` 和电压余量，先证明代码、遥测和方程一致。若离线已能分解交叉项和反电动势项，就先不改Scope。

2026-08-27的A阶段审计结论为：Clarke/Park和反Park采用同一电角度正方向；机械rpm经极对数转换为电角速度rad/s；前馈使用滤波后的实测电角速度和实测 `Iqd`，不是参考电流；IDENTIFIED参数单位为H/Wb。总电压经过 `Vbus/sqrt(3)` 等比例矢量限幅后，PI分别跟踪 `uq_applied-uq_ff` 与 `ud_applied-Vd_bias-ud_ff`，坐标和饱和回算一致。主机C++回归同时覆盖四模式公式、正反速度符号和每种模式限幅后的tracking。

历史数据能回答：总前馈在现有空载旋转工况重复降低PI电压约86%/88.5%，BEMF理论幅值在中高速占主导，±1 A d轴激励下CROSS q轴项约为可观测的0.04–0.08 V量级；现有范围最大电压利用率仍低于约30%，没有饱和。历史数据不能回答：CROSS与BEMF各自的实测收益、两者交互、LEGACY/IDENTIFIED的可靠排序、`voltage_scale<1`时的PI恢复，也不能支持带载解耦、效率或恒功率结论。D-043局部阶跃能补充q轴动态，但没有分项模式码和快速 `voltage_scale`，不能反事实拆分旧的BOTH记录。

### 4.2 分项前馈的可观测性

离线审计确认合并开关妨碍物理归因，且±3000 rpm、±1 A范围内CROSS/BEMF理论幅值高于现有电压数值分辨率，因此最小固件增量已采用：

~~~text
FF MODE OFF
FF MODE CROSS
FF MODE BEMF
FF MODE BOTH
~~~

保留 `FF ON/OFF` 为兼容别名，模型选择仍由 `FF MODEL LEGACY/IDENTIFIED`负责。第一版不增加连续比例参数，也不把Rs前馈、母线补偿和模型缩放一次性混入同一实验。

分项物理含义：

- BEMF主要随 `omega_e*flux`增长，空载中高速最容易观察，预期主要减少q轴PI维持电压；
- CROSS随 `omega_e*Ld*id`、`omega_e*Lq*iq`增长，需要旋转速度和非零轴电流共同激励；
- Rs压降在稳态与电流同相，当前PI积分已经能够承担。是否加入 `Rs*i`前馈应作为后续单独假设，不能用它掩盖电流偏置或逆变器等效压降。

### 4.3 解耦实验

自由转子不适合直接大q轴阶跃：既有0.5 A短脉冲已快速加速。优先采用两类安全激励：

1. 速度环维持正反中高速偏置，在d轴叠加有界小阶跃或正弦，观察q轴误差与速度扰动；
2. 用速度参考的小阶跃/正弦间接激励q轴，同时观察d轴误差。

测试矩阵应至少包含正反方向和反序访问，以分离符号错误与温漂/顺序漂移。具体速度、电流和频点由离线电压余量与首轮冒烟决定；可从既有已验证的±1500/±3000 rpm和不超过±1 A d轴范围起步，而不是把这些值写成永久上限。

### 4.4 电压约束与饱和恢复

先定义可量化变量：

~~~text
U_limit = Vbus/sqrt(3)
U_request = sqrt(uq_request^2 + ud_request^2)
voltage_utilization = U_request/U_limit
voltage_scale = min(1, U_limit/U_request)
~~~

首轮只统计各模式在速度扫描中的电压利用率和最小裕量。如果最高已验证速度仍远离限幅，应明确记录“当前范围未触及约束”，再讨论是否提高速度或改变激励；不能为了出现饱和而盲目扩大工况。

真正进入约束实验时，至少观察：

- `voltage_scale<1`的样本占比、连续最长时间和最小值；
- d/q电流误差在进入、维持和退出饱和三段的RMS/峰值；
- PI积分恢复是否产生退出后的反向过冲或长尾；
- 前馈OFF/CROSS/BEMF/BOTH是否改变饱和进入点和恢复质量；
- 正反方向和重复轮次是否一致。

当前等比例矢量限幅与VESC的d轴优先策略不同。阶段3先验证现有策略，不提前假定必须改成d轴优先；只有弱磁需要、或实验显示等比例限幅破坏关键d轴目标时，再形成独立设计决策。

### 4.5 模型敏感性与默认策略

LEGACY/IDENTIFIED只在以下条件成立时重新排序：

- 同一分项、同一轨迹、正反和反序重复；
- 差异大于组内重复波动与测量噪声；
- 跟踪误差、跨轴误差或电压约束至少一项有一致改善，且其他关键项不恶化。

必要时可以离线做±参数扰动敏感性分析，帮助选择更可观测的工况；不要为了“证明辨识模型更好”而后验挑选单点。若两模型仍不可分辨，阶段3可以以“总前馈有效、参数版本不可分辨”正常退出。

## 5. 简明评价标准

不建立复杂加权总分。每次实验只保留四类结果：

| 类别 | 主要量 | 实际控制意义 |
|---|---|---|
| 有效与安全 | 完整记录、最终STOP/READY、电流/速度/母线边界 | 结论可信且测试不会以失控换取数据 |
| 跟踪与解耦 | 主轴误差RMS/峰值、非激励轴误差RMS、正反/重复差 | 判断前馈是否真正减轻轴间干扰，而非只搬运控制电压 |
| 控制代价 | PI电压RMS/峰值、前馈电压RMS/峰值 | 判断模型是否承担了可预测电压，给反馈留下动态余量 |
| 电压约束 | 利用率、饱和占比/最长时间、退出恢复误差 | 决定能否支撑高速、弱磁和电压受限运行 |

候选升级默认的原则是“在预先冻结的代表工况中重复改善目标量，且不引入新的跟踪或饱和退化”。具体数值阈值应在首批基线数据后冻结，避免用缺少噪声尺度的任意百分比写死整个阶段。

- 只有合并开关确实妨碍归因时，增加OFF/CROSS/BEMF/BOTH；

### C. 有裕量的分项A/B

- 从已验证工况内选择正反速度、d轴小激励和速度环q轴间接激励；
- 先证明分项符号与收益，再增加速度/电流点；
- 一次连续实验完成模式和顺序组合，异常与正常退出均STOP。

首批已冻结为最小两轮反序矩阵：IDENTIFIED模型下依次访问 `OFF/CROSS/BEMF/BOTH`，第二轮完全反序；每次覆盖 `±1500/±3000 rpm × id=0/±1 A`，两轮同时反转速度和d轴顺序；每次访问只在首方向的±3000 rpm执行一份D-043型300 rpm局部阶跃Scope。总计8次访问、96个稳态点和8份40 kHz Scope。运行时边界为4 A速度q轴参考、5 A实际dq、3500 rpm、18–28 V和0.90缩放中止线；0.98只作首批有裕量评价线，不把它冒充饱和实验。

状态：D-057已完成96/96稳态点和8/8 Scope，最终READY并恢复默认。BOTH/OFF两轮PI电压降幅87.17%/87.20%；BEMF稳态q轴斜率1.00075、相关0.99997，CROSS q轴斜率1.0996、相关0.9667。CROSS在两方向局部阶跃中重复将id误差RMS降低约0.040 A、iq误差RMS降低0.010–0.014 A。最大请求利用率25.35%，全程 `voltage_scale=1`。

停止点：若CROSS分项低于可观测度，不用更大电流强行证明；可以只冻结BEMF结论并记录边界。

### D. 电压边界与模型敏感性

- 根据C的实际利用率决定是否安全提高速度或激励；
- 验证限幅占比、anti-windup/PI tracking恢复和前馈影响；
- 在可观测条件下才比较LEGACY/IDENTIFIED或参数扰动。

D-057说明当前安全范围无法自然触发限幅；D-058因此只增加复位为1的测试电压上限比例和Scope `voltage_scale`通道，不重复四模式或模型网格。比例固定为0.22：SVPWM测试上限为 `0.22*Vbus/sqrt(3)`，但调制器仍使用实测Vbus。连续矩阵固定IDENTIFIED模型、OFF/BOTH、正反方向和两轮反序，在±3000 rpm基点施加±3300 rpm短脉冲，每批8次访问/8份Scope。

D-058共完成三批。前两批40 kHz短窗的最小缩放为0.86842/0.86399，证明受控进入限幅，但102.4 ms记录无法容纳完整速度恢复。第三批不改变固件和运动边界，只把Scope改为4 kHz、1.024 s，并在100–140 ms施加脉冲。OFF/BOTH的脉冲前→末尾速度误差RMS分别为39.69→39.39 / 40.34→39.77 rpm，iq误差为0.161→0.179 / 0.166→0.188 A，PI电压偏移均值仅0.0306/0.0166 V，证明现有等比例限幅和applied-voltage PI tracking在两种模式下均能退出恢复。3000 rpm基点会偶尔触碰0.22人工上限，所以不再使用“最后一个 `scale<1` 样本”定义恢复时间。

停止点：形成默认策略和阶段4可复用的电压约束接口；不能触及边界时明确记录实验限制，不伪造饱和结论。

# 速度环经验自整定规范

本文冻结阶段 2 速度环经验自整定 v1.0 的输入、候选生成、连续实验、验收标准、带宽护栏和输出语义。实现不得根据硬件结果后验修改本版标准；确需调整时，应先在 `docs/DECISIONS.md` 建立新版本并保留原始结果。

> 执行状态（2026-08-25）：D-043 的32份阶跃和四次正反4000 rpm斜坡已经完成。`fc24_pm70` 在D-042只失败带宽一致性，但在独立收尾时域测试中显著优于历史默认，因此以工程选择写为复位默认；速度 PI搜索结束。

## D-039/D-040 当前最小工作流

当前不再把 D-033 的经验 P 扫描作为第一入口。已有 D-038 闭环频响时，优先使用
`P=T/(1-T)/C0` 恢复实测对象，然后由目标闭环带宽和 65°相位裕度生成六组 PI。这样
仍不需要辨识低可信的 J/B，也不依赖某个“已经不错”的默认 PI作参数种子；默认 PI只
作为已知测试控制器参与对象反算。

D-040 只做模型资格验证：`±1500 rpm` 偏置、100 rpm 正弦、4–60 Hz 的 11 个公共频点，
六组正向升序、反向降序，共 132 份 scope。标准保持简明：带宽预测误差 `<=20%`、峰值
`<=2 dB`、方向带宽差 `<=15%`、不触及电流限幅。通过只表示有资格进入后续阶跃和
轨迹性能比较，不代表已经选定最终 PI。

实际结果中 15 Hz 候选为 `14.26/13.95 Hz`，20 Hz 候选为 `17.57/17.27 Hz`，两组
通过；25 Hz 候选反向误差 `20.77%`，其余高目标也失败。所有候选峰值均低于 2 dB，
全批 `iq_ref` 仅到 `0.981 A`，说明限制来自对象/PI 带宽映射，而非 4 A 电流限幅。
从 25 Hz 起实测交越偏低、PM 升到约 67–80°；若后续追求更高带宽，应作为新的鲁棒
对象迭代，不把这些失败者直接送入性能排名。

## D-041 高频对象边界探测

D-041 不把 100/150 Hz 当作待运行的速度 PI。它只用已经在 D-040 保持稳定的
`bw20_pm65` 和 `bw40_pm65` 作测量控制器，在 `±1500/±3000 rpm` 偏置、`100/300 rpm`
幅值下扫描 `40/50/60/70/80/100/120/150 Hz`。16 次连续访问、每次 8 个频点，共
128 份 scope；固定 WIN、前馈关闭和 4 A `iq_ref` 限幅，不修改固件或默认参数。

每点由 `T` 反算 `L=T/(1-T)`，再由已知 PI 得到 `P=L/C`。只使用四种直观判据：

1. 参考正弦幅值误差不超过 2%；
2. 实测速度正弦拟合 SNR 不低于 6 dB；
3. 对象在控制器、幅值、1500/3000 rpm 和正反方向之间的成对差异不超过 `2 dB/10°`；
4. 用 `180°+∠P` 报告普通 PI 理论最大相位裕度：`>=65°` 为绿色，`50–65°` 为黄色，`<50°` 为红色。

绿色表示若 PI 再引入约 10°滞后，仍有约 55°裕度；黄色需要谨慎设计或相位超前，红色
则不继续用普通 PI硬推带宽。该分区用于选择下一轮候选范围，不替代阶跃、峰值、跟踪误差
和电流代价评价。脚本每采一份 scope 都原子更新 JSON，串口中断后可续跑；退出时必须
STOP/READY并恢复 WIN和源码默认速度 PI。

实际硬件已完成 128/128，峰值 `iq_ref=2.787 A`、实际 dq `3.494 A`、转速
`3281.6 rpm`，最终 READY并恢复默认。两次 Windows CDC错误均在 STOP/READY后从检查点
续跑。严格聚合没有合格频率，因为每个 16 点组都含 SNR不足的弱测量组合，冻结门槛未
修改。

固定的 `bw40_pm65 + 300 rpm` 子集仅作为诊断：它在 40–100 Hz的四个速度偏置全部达到
SNR要求，对象相位中值为 `-105/-118/-126/-136/-146/-164°`。40 Hz为绿色且重复差
`0.45 dB/2.30°`；60 Hz为黄色且差 `0.36 dB/3.14°`；50 Hz黄色但幅值差
`2.005 dB` 略超冻结线；70 Hz以上进入红色或一致性失败。这一子集与此前 40–80 Hz
相位趋势一致，但不改写严格 D-041 结果。

由此得到的设计边界是“普通 PI开环交越约 40–50 Hz可信，60 Hz接近边界”，不是“闭环
带宽只能到 40–50 Hz”。100/150 Hz不进入普通 PI候选，若继续追求需另行评价测速延迟、
相位超前或更高阶控制器。

D-042 改用开环交越这一直接设计量：`22/24/26/28/30/32 Hz`，名义 PM统一 70°。
六组 Kp 为 `0.005100–0.006452`、Ki 为 `0.213116–0.373188`；四速度包络下预测最小
PM `62.41–69.68°`、最大峰值 `1.79–2.00 dB`、200 rpm最大电流幅值
`1.58–2.31 A`，均通过离线预筛。闭环 `-3 dB` 带宽只由硬件报告。

硬件批次使用两个既有稳定锚点加六组新候选，在 `±1500/±3000 rpm`、200 rpm正弦下
扫描 14 个 `4–100 Hz` 频点，共 448 份 scope。性能资格只保留四条：交越目标误差

实际硬件已完成 448/448，最终 READY并恢复默认 PI，安全峰值为

## D-043 默认 PI与 fc24收尾 A/B

项目接受约50 Hz级速度环作为当前目标，不再扩展高带宽候选。D-043 只比较源码默认
PI与 `fc24_pm70`：两组各两次反序访问，连续斜坡覆盖正反500/1500/3000/4000 rpm，
并采集 `0↔±1500 rpm` 大阶跃和 `±3000 rpm` 附近300 rpm局部阶跃，共32份scope。
大范围覆盖不包含正4000到负4000 rpm的直接全反转。

现有速度 PI已经使用积分限幅和输出饱和回算。4 A `iq_ref` 限幅生效时，超出的PI输出
会即时回跟到积分器；本轮不增加另一套 anti-windup。大阶跃不作为线性带宽点，而用于

实验脚本本身不烧录、不写默认，正常或异常退出都必须 STOP/READY并恢复运行前默认。

## 目标与边界

目标是在已经验证并写回电流 PI 后，不依赖既有速度 PI，也不强制辨识转动惯量、黏性阻尼或摩擦参数，通过受约束的自动 P 扫描和少量 PI 候选实测，为新电机生成可解释、可复现的速度 PI。

本版只支持编码器有感、空载自由转子。结果只代表当前电机与机械配置，不外推到带桨、带载、效率、热稳定或车辆级工况。速度环完成并写回后，位置环另立规范，不与本轮联合搜索。

## 已冻结的控制结构

- 电流环 40 kHz，D-032 实测鲁棒带宽 969.5 Hz；
- 速度环 4 kHz，控制器为并联 PI；
- 输入为电角速度误差，单位 rad/s；
- 输出为 q 轴电流参考 `iq_ref`，单位 A；
- d 轴电流参考保持 0；
- 初始整定关闭 dq 前馈，避免把前馈差异混入 PI 评价；
- 候选只通过运行时命令易失切换，最终推荐通过留出后才允许写入源码。

速度环执行频率不是闭环带宽。级联分离和数字控制共同给出上限：

\[
f_{speed,max}=\min\left(\frac{969.5}{5},\frac{4000}{20}\right)
\approx 194\ \mathrm{Hz}
\]

为保留实现与测量余量，本版冻结为：

\[
\boxed{f_{speed}\le 190\ \mathrm{Hz}}
\]

190 Hz 只作为最终领先者的护栏，不作为候选奖励，也不意味着带宽越高越好。

## 输入契约

主机工具必须读取或显式记录：

- 极对数与 rpm/电角速度换算；
- 电流环鲁棒带宽和当前默认 d/q PI；
- 速度环执行频率；
- 实验 `iq_ref` 限幅、实际 dq 电流中止阈值、转速和电压中止阈值；
- 零速速度噪声；
- 每组命令、访问顺序、固件基线和原始数据路径。

旧速度 PI 不作为候选生成、门槛或排名输入。它可在推荐冻结后作为附加对照，但不是写回前置条件。

## 阶段 A：受约束的 P 扫描

先固定 `Ki=0`，使用 `±500 rpm` 阶跃寻找合理 Kp 区域。第一点通过允许的初始 P 电流命令计算：

\[
K_{p0}=\frac{I_{q,seed}}{\Delta\omega_e},\qquad
\Delta\omega_e=\Delta n\frac{2\pi}{60}N_p
\]

本版取 `Iq_seed=0.5 A`。对 10 极对、500 rpm 阶跃，`Kp0≈0.000955 A/(rad/s)`。候选从该安全点按 1.5 倍几何增长，最多六组：

\[
K_p=K_{p0}\{1,1.5,1.5^2,1.5^3,1.5^4,1.5^5\}
\]

每个 Kp 执行正负阶跃。出现不衰减振荡、命令无效、实际 dq 电流达到 5 A、转速达到 4800 rpm、电压利用率达到 98%，或 `iq_ref` 连续贴住 4 A 超过 50 ms 时立即停止扩大 Kp。P-only 允许摩擦和空载损耗造成静差，因此此阶段不要求稳态均值进入最终目标带；要求 63.2% 响应可观测且相对命令的超调不超过 10%，在合格安全点中选择最坏 `tau63` 最短者作为 `Kp_base`。P 扫描只确定搜索中心，不直接写回。

## 阶段 B：八组 PI 候选

从 `Kp_base` 正负响应计算 63.2% 响应时间，取两方向中位数 `tau`。首次六组网格的积分过强；随后同时降低 Kp/Ki 的网格又显示比例阻尼不足。最终八组据此把两者分开：保留中高 Kp 提供阻尼，只延长积分时间以压低 Ki。按工业积分时间形式：

\[
K_i=\frac{K_p}{T_i}
\]

固定生成八组候选：

| Kp | Ti | 含义 |
|---|---|---|
| `0.55*Kp_base` | `16*tau` | 中等比例阻尼、较慢积分 |
| `0.55*Kp_base` | `24*tau` | 中等比例阻尼、最慢积分 |
| `0.70*Kp_base` | `16*tau` | 中高比例阻尼、较慢积分 |
| `0.70*Kp_base` | `24*tau` | 中高比例阻尼、最慢积分 |
| `0.85*Kp_base` | `16*tau` | 较高比例阻尼、较慢积分 |
| `0.85*Kp_base` | `24*tau` | 较高比例阻尼、最慢积分 |
| `1.00*Kp_base` | `16*tau` | P 边界比例阻尼、较慢积分 |
| `1.00*Kp_base` | `24*tau` | P 边界比例阻尼、最慢积分 |

若 P 扫描无法得到有效 `Kp_base/tau`，状态为 `seed_failed`，不使用旧 PI 兜底继续搜索。

## 连续硬件筛选

八组 PI 第一轮按生成顺序、第二轮按反序访问。每次切换候选时依次执行：速度命令清零、等待低速、设置 PI、清除控制器状态、执行工况、回零并确认有效遥测。

所有候选先执行：

- 0→`±500 rpm` 阶跃；
- 以 3000 rpm/s 斜坡进入 `±1500 rpm` 工作点后，执行正负 300 rpm 局部阶跃；
- 两轮反向访问。

0→±1500 rpm 的首次测试会直接触及 4 A 限流，更适合作为大指令加速能力数据，而不是线性 PI 品质门槛，因此不再混入候选筛选。

通过低中速标准的候选继续执行：

- 0→+3000→+4000→0 rpm 斜坡；
- 0→−3000→−4000→0 rpm 斜坡；
- `±3000 rpm` 工作点附近 300 rpm 局部阶跃；
- `±4000 rpm` 工作点附近 200 rpm 局部阶跃。

高速正反方向分别从零速进入，不执行 +4000→−4000 rpm 全反转。高速斜坡评价跟踪误差、限幅和结束恢复；局部阶跃评价高速工作点动态。

## 简明验收标准

安全中止与性能验收分开。中止阈值不参与候选排名。

### 安全与有效性

- 速度实验 `iq_ref` 限幅为 4 A；
- 实际 dq 电流达到 5 A 时中止；
- 机械转速达到 4800 rpm 时中止；
- 电压利用率达到 98% 时中止；
- `iq_ref` 连续贴住 4 A 超过 50 ms 时，该候选性能无效；
- 串口、参考、模式或采集异常时立即 STOP；
- 正常或异常退出都必须确认最终 READY。

### 三项性能标准

1. **超调**：所有评价阶跃的滤波后超调不超过 10%。
2. **整定与误差**：整定带为 `max(10 rpm, 2%×|reference|, 3×速度噪声)`；低中速和高速局部阶跃均须在 150 ms 内进入整定带，捕获末段平均误差也须位于同一带内。
3. **一致性**：正负方向差和两轮重复差分别不超过 15%，以最坏上升/整定时间聚合结果判定。

除三项硬标准外，报告峰值/RMS `iq_ref`、实际电流、速度误差和电压利用率，作为合格候选间的控制代价比较，不再构造加权总分。

## 排名和带宽护栏

只对三项性能标准、安全和数据完整性全部通过的候选排名：

1. 最坏整定时间更短；
2. 若整定时间相差不超过 10%，选择峰值和 RMS `iq_ref` 更低者；
3. 若仍接近，选择方向/重复差更小者；
4. 最后选择 Kp、Ki 更小的保守方案。

只对冻结领先者执行 6–8 个同步速度正弦点。频点围绕阶跃估计带宽生成并覆盖到 190 Hz。领先者必须满足：

- 实测 -3 dB 带宽不超过 190 Hz；
- 闭环幅频峰值不超过 +2 dB；
- 频响连续，无参考失真或持续电流限幅。

若 190 Hz 前仍未测得 -3 dB，或出现超过 +2 dB 的峰值，则不写回。

## 独立留出与停止条件

领先者和全部标准冻结后，只执行一次未见点留出。v1.0 留出固定包含：

- `±800 rpm` 阶跃；
- 斜坡进入 `±2200 rpm` 后执行 250 rpm 局部阶跃；
- 斜坡进入 `±3500 rpm`；
- 斜坡进入 `±4200 rpm` 后执行 200 rpm 局部阶跃；
- 两次访问交换正负顺序。

留出继续使用同一安全、超调、整定/误差和一致性标准。通过后才允许把速度 PI 写入源码并做复位后默认参数回归；失败则保留现役速度 PI，状态为 `holdout_failed`，不自动改用第二名、不放宽门槛、不追加本轮候选。

## 自动化与供电工作流

一次硬件批次可以在 24 V 持续接通时完成，不要求候选之间上下电或反复烧录。用户在批次开始前确认供电、自由转子和环境安全；只要连接、机械状态和现场条件没有改变，脚本在该批次内连续执行。

主机监督器固定流程为：

```text
READY/母线检查
→ 零速噪声
→ P 扫描
→ 计算6组PI
→ 两轮低中速筛选
→ 合格候选高速覆盖
→ 冻结领先者
→ 领先者带宽护栏
→ 独立留出
→ 恢复默认参数
→ STOP并确认READY
→ 保存原始CSV/JSON和正式摘要
```

候选失败只改变报告状态，不触发多层兜底或无限搜索。编译、烧录和默认参数回归属于领先者留出通过后的独立步骤，执行前仍需明确告知用户。

## 最小实现范围

固件只增加确定性实验和安全所需能力：

- 速度 PI 输出限幅可在 READY 下设置，并在 PI 内部参与反积分饱和；
- `SPEED SINE amplitude_rpm frequency_hz` 同步参考；
- 软件示波器可观测速度参考、速度反馈和 `iq_ref`；
- `PI CLEAR` 的实现与文档一致；
- 所有 STOP 路径取消正弦、清零参考并回到 READY。

Python 负责安全起点、候选生成、连续编排、指标计算、排名、留出和报告。第一版不建立通用在线自整定框架，也不把搜索逻辑放入 40 kHz 中断。

## 输出语义

- `seed_failed`：安全 P 扫描无法产生有效中心；
- `screen_failed`：没有 PI 通过正式筛选；
- `bandwidth_guard_failed`：领先者违反 190 Hz/+2 dB 护栏；
- `holdout_failed`：领先者未通过独立留出；
- `qualified`：领先者筛选、带宽护栏和留出全部通过，可进入默认写回；
- `default_verified`：写回后构建、烧录和复位默认参数回归完成。

任何失败状态都必须保留原始数据和当前可用默认 PI，不通过事后改标准制造推荐结果。

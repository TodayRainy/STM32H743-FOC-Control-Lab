# ABZ 编码器角度与速度估算评估规范

本文冻结阶段 2 外环整定前的编码器反馈评估边界。目标不是预先选择 PLL，而是先确认角度换算正确，再用同一批数据比较少量速度估算方法。测速器取得资格前，不继续执行速度 PI 候选硬件筛选，也不根据现有约 25 Hz 速度闭环结果推断机械对象的真实带宽上限。

## 已确认的现状

- ABZ 使用 TIM3 编码器模式，计数范围为 `0..4095`，即 4096 count/rev；
- 机械角度直接由计数换算，电角度由机械角度乘极对数并叠加方向和零偏得到；
- 角度链路不使用 PLL，继续作为 FOC 换相、位置反馈、方向与 Z 相校准的基准；
- 速度在 40 kHz 下对电角度差分，再经过 500 点滑动平均；
- 该速度算法等价于 12.5 ms 固定窗口的位置增量法，而不是独立的 500 次速度测量平均：

\[
\hat\omega[k]
=\frac{1}{N}\sum_{i=0}^{N-1}\frac{\theta[k-i]-\theta[k-i-1]}{T_s}
=\frac{\theta[k]-\theta[k-N]}{NT_s},\quad N=500
\]

其理论群延迟约 6.24 ms，首个陷波点为 80 Hz，矩形窗自身的 -3 dB 频率约 35.4 Hz。现有速度频响在 80/160 Hz 近乎为零与这些陷波点一致，因此当前速度反馈链已经参与限制所测闭环结果。

## 角度链路边界

角度第一步只修正计数归一化：计数器共有 `ARR+1` 个状态，机械角度应按

\[
\theta_m=\frac{\mathrm{CNT}}{\mathrm{ARR}+1}2\pi
\]

计算。当前 `CNT/ARR` 会把最后一个计数映射到 `2π`，随后回到计数 0 时形成一次重复角度样本。修正后必须离线检查边界计数，并在首次硬件批次验证：

- 0、1、4094、4095 及回绕处角度步长连续；
- 正反转符号与 Z 相/零偏逻辑不变；
- 电角度每机械圈连续，未引入额外跳变；
- 修正前后的零偏差异有记录，不把测速器变化误判为校准变化。

第一版不让 PLL 代替原始编码器角度。若后续证明位置预测能降低延迟，预测角度只能作为单独候选，并始终保留原始计数角度用于校准、故障检查和对照。

## 速度估算候选

候选只保留一个现状基线和三类方法，不扩展为通用观测器框架。

| 标识 | 方法 | 第一轮作用 |
|---|---|---|
| BASE | 12.5 ms 差分/500 点矩形窗 | 保留现状基线和既有结果解释 |
| WIN-IIR | 1–2 ms 位置差分 + 可调一阶或二阶低通 | 最小改动、低延迟基准 |
| M/T | 固定窗口计数与边沿周期/自适应计数窗口融合 | 宽速域工业基准，重点改善低速量化 |
| PLL | 编码器位置跟踪 PLL/等价 α-β 观测器 | 连续速度与计数间插值候选 |

仓库已有 `foc_pll` 服务于 SMO、HFI 等无感路径，不作为编码器 PLL 直接复用。编码器候选必须使用统一离散时间定义、明确带宽单位，并能以原始计数重放测试。

## 统一评价

不构造复杂加权总分。所有候选只比较四类指标：

1. **静止与低速**：零速速度均值/RMS、虚假非零持续时间、最低可稳定分辨速度和正反向一致性；
2. **稳态纹波**：在相同原始计数上比较速度均值误差、RMS 和一圈周期性纹波，不让滤波后的平滑外观代替准确性；
3. **动态延迟**：使用相同输入计算估算器幅频、相频、-3 dB 点、明显峰值或陷波，并报告阶跃/换向延迟；
4. **控制适用性**：接入速度环后不产生静止抖动、持续振荡、方向异常或额外电流代价，且目标速度环工作频段必须位于测速器可靠频段内。

测速器带宽不是越高越好。第一轮先得到噪声—延迟曲线，再确定速度环目标和测速器截止频率；原 D-033 的 `190 Hz` 只保留为由电流环和执行频率得到的设计上限，不再作为当前测速链已经具备的能力。新的速度环上限必须同时受电流环、4 kHz 执行频率和实测测速器相位/幅值约束。

## 分步工作流与停止条件

1. 修正并回归验证 `ARR+1` 角度归一化；
2. 主机侧建立四种方法的统一离线重放，先使用已有数据检查中高速和频率特性；
3. 若现有记录没有原始计数或边沿时间信息，只增加最小观测量，不借机扩展串口/示波器框架；
4. 离线淘汰有固定陷波、过大延迟、低速失效或参数范围不清楚的方案；
5. 最多选择两种新方法，加 BASE 做一次连续硬件 A/B；
6. 冻结测速器后，重新测量速度反馈频响，再恢复 D-033 的速度 PI 整定并重定其带宽护栏。

若简单 WIN-IIR 已满足目标速度环的噪声和相位要求，不因“算法更先进”继续增加复杂度。若低速量化仍是主要问题，优先晋级 M/T；若动态延迟和连续速度是主要问题，优先晋级 PLL。没有硬件 A/B 证据前，不写回默认测速器。

## 当前离线进度

2026-08-25 已完成第一步、统一合成筛选和上板 A/B 准备：

- `FOC_ABZENC_HW_GetMechAngle()` 已改为调用纯函数 `foc_encoder_count_to_mech_angle(CNT, ARR)`，内部按 `ARR+1` 归一化；
- 主机回归覆盖 0、1、4095、正向回绕和全部 4096 个步长，机械角每计数约 `0.00153398 rad`，最大浮点步长误差约 `4.73e-7 rad`；
- `tests/encoder_speed_estimation.py` 可在同一电角度记录上重放 BASE、WIN-IIR、编码器 PLL 和采样式自适应计数方法；专项回归覆盖矩形窗特性、80 Hz 陷波、回绕恒速、PLL 收敛和固件候选选择；
- 20 Hz 既有速度正弦记录上，离线 BASE 与固件 `elec_speed` 的 RMSE 约 `0.512 rad/s`，相对约 `200 rad/s` 的动态量很小，支持固定窗口等价关系；
- `tests/encoder_speed_estimation_sweep.py` 在 40 kHz、4096 count/rev、10 极对下统一扫描 1–4200 rpm 与 2–160 Hz。首批选择动态接近的 `WIN=1 ms+150 Hz` 和 `PLL=200 Hz`：两者在 40 Hz 分别约 `-0.32/-0.35 dB、-21.8/-22.2°`，80 Hz 分别约 `-1.18/-1.32 dB、-41.8/-42.7°`，10 rpm 量化纹波约 `1.24/1.20 rpm RMS`；机器可读结果为 `tests/baselines/encoder_speed_estimation_synthetic_20260825.json`；
- 当前采样式自适应计数候选在 500 rpm 合成工况仍有约 `4.41 rpm` 均值偏差，未进入首批上板。这不否定带真实输入捕获时间戳的 M/T，只说明现有采样角度不足以公平实现它；
- 固件已经并行计算 BASE/WIN/PLL，并提供只在 READY 接受的 `SPEED EST` 临时切换命令；D-037 后 ABZ 复位和脚本退出均恢复 WIN，角度换相链不变。`tests/encoder_speed_estimation_validation.py` 固定两轮反序、每次访问 12 份 scope：`±50/±500/±1500/±3000 rpm` 稳态点和 100 rpm 幅值的 20/40/80 Hz 零均值正弦，共 72 份记录；
- 既有 scope 只有采样后的 `elec_angle/elec_speed`，没有原始 TIM3 计数边沿时间。它足以初筛 WIN-IIR/PLL 的延迟和量化表现，但不能公平重建真实 M/T，也不能把离线重放当作新测速器已经闭环合格。

首批硬件 A/B 已完成：两轮反序 72 份 scope 全部采集，峰值 dq 电流 `0.947 A`、峰值 `iq_ref=0.394 A`，最终 READY 并恢复 BASE。两轮平均闭环幅值如下：

D-037 只在 ABZ 对象构造后把默认反馈设为 `WIN=1 ms+150 Hz IIR`；通用 `foc_speed` 构造默认与无感链路不变。默认固件构建为 0 error、0 warning，Flash `107916 B`、RAM `221092 B`，并通过指定 J-Link V7.54d 原始烧录与代码读回。`tests/encoder_speed_default_smoke.py` 不发送 `SPEED EST`，在 +1500 rpm、100 rpm/80 Hz 下得到 `-19.73 dB/-138.24°`、峰值 dq 电流 `0.596 A`，最终 READY，确认复位默认确为 WIN。

## 硬件与文档边界

- 角度换算、离线重放、主机测试和文档更新不需要 24 V；
- 烧录后只做静态编码器读数时需连接目标，但不应启动电机；
- 任何自动旋转、换向或速度环 A/B 前，仍需用户当次确认 24 V、自由转子和周围安全；
- 正常或异常退出均必须 STOP、确认 READY并恢复当前默认 WIN；
- 原始数据、候选参数、固件基线和结论分别进入 `tests/results`、`tests/baselines`、`PROJECT_STATUS` 和 `VALIDATION_REPORT`，不依赖聊天记录恢复。
